大模型常用注意力机制详解

从 MHA 到 FlashAttention —— 驱动大语言模型的核心引擎
MHA GQA / MQA FlashAttention Sliding Window Sparse Attention Linear Attention MLA

引言：注意力机制的核心地位

注意力机制是 Transformer 架构的灵魂，也是大语言模型能够理解长上下文、捕捉远距离依赖的关键。 然而，标准注意力的 O(N2) 时间和内存复杂度，以及推理时的 KV Cache 内存瓶颈，催生了大量优化方案。

两大优化方向： (1) 计算效率——如何更快地计算注意力（FlashAttention、稀疏注意力、线性注意力）； (2) 内存效率——如何减少 KV Cache 的显存占用（GQA、MQA、MLA）。
图 1：注意力机制在大模型中的演化时间线（2017-2025）。

一、多头注意力（MHA）—— 基线方案

1.1 回顾

标准多头注意力（Multi-Head Attention）是原始 Transformer 提出的方案。 每个头有独立的 Q、K、V 投影矩阵：

headi = Softmax(Qi KiT / √dk) · Vi

MultiHead = Concat(head1, ..., headh) · WO

对于 LLaMA-7B（h=32, dk=128），每层有 32 个独立的 Q、K、V 头。 这意味着推理时每个 token 需要缓存 32 组 K 和 32 组 V。

1.2 MHA 的问题

KV Cache 膨胀：在批量推理中，KV Cache 的内存消耗与注意力头数成正比。 以 LLaMA-65B（64 头，80 层）为例，生成 4096 个 token 的 KV Cache 就需要约 10 GB。 batch=8 时需要 80 GB——超过单张 A100 的显存。这严重限制了推理吞吐量。

二、GQA 与 MQA —— KV Cache 压缩

2.1 Multi-Query Attention（MQA）

MQA（Shazeer, 2019）的思路极为大胆：所有 Q 头共享同一组 K 和 V。

MQA:   Q 有 h 个头，K 和 V 只有 1 个头（所有 Q 共享）

KV Cache 直接缩减为原来的 1/h。对于 32 头模型，内存减少为 1/32。 代价是轻微的质量损失——因为所有 Q 头被迫使用同一套 K、V 来检索信息。

2.2 Grouped-Query Attention（GQA）

GQA（Ainslie et al., 2023）是 MHA 和 MQA 之间的折中：将 Q 头分成 g 个组， 同组内的 Q 头共享一组 K 和 V。

GQA:   Q 有 h 个头，K 和 V 有 g 个头（h/g 个 Q 共享一组 KV）

g = h → MHA  ;  g = 1 → MQA
图 2：MHA、GQA、MQA 的结构对比。MHA 中 Q 和 K/V 一一对应（8 对 8）； GQA 每 4 个 Q 共享 1 组 K/V（8 对 2）；MQA 所有 Q 共享同一组 K/V（8 对 1）。
图 3：GQA 如何减少 KV Cache。左侧 MHA 每个 Q 头有独立的 K/V（100% 内存）， 右侧 GQA 每组共享 K/V（仅 25% 内存），质量损失极小。

三、FlashAttention —— IO 感知的高效注意力

3.1 问题：内存墙

标准注意力的瓶颈不是计算量，而是内存访问。GPU 有两级存储：

  • SRAM（片上缓存）：极快（~19 TB/s），但极小（A100 仅 20 MB）
  • HBM（显存）：较慢（~2 TB/s），但大（A100 有 80 GB）

标准注意力需要将 N×N 的注意力矩阵写入 HBM 再读回来做 Softmax， 这些显存读写操作（IO）才是真正的速度瓶颈。

3.2 FlashAttention 的核心思想

核心策略：分块计算（Tiling）——将 Q、K、V 分成小块，每次只加载一小块到 SRAM 中， 在 SRAM 内完成注意力计算（包括 Softmax），然后将结果写回 HBM。 整个过程从不在 HBM 中存储完整的 N×N 注意力矩阵。
图 4：标准注意力（左）需要在 HBM 中存储完整的 N×N 矩阵， FlashAttention（右）通过分块计算避免 N×N 矩阵的物化，内存降为 O(N)，速度提升 2-4 倍。

3.3 技术难点：在线 Softmax

分块计算的最大挑战是 Softmax 需要知道全局最大值（用于数值稳定）。 FlashAttention 使用了 Online Softmax（Milakov & Gimelshein, 2018）技巧：

  1. 处理每个 K 块时，维护当前的局部最大值和指数和
  2. 当遇到更大的值时，回溯修正之前所有块的计算结果
  3. 最终结果与全局 Softmax 在数学上完全等价——没有任何近似

核心价值：FlashAttention 是一个精确的算法（非近似）， 计算结果与标准注意力逐比特一致。它不改变模型的数学定义，只改变计算的执行方式。 目前几乎所有 LLM 训练和推理框架都默认使用 FlashAttention。

四、滑动窗口注意力（Sliding Window Attention）

4.1 核心思想

滑动窗口注意力（SWA）由 Mistral 7B（Jiang et al., 2023）推广。其核心假设： 大部分重要信息来自局部上下文，因此每个 token 只需关注最近的 w 个 token。

SWA: token 在位置 i 只能关注位置 [i-w+1, i]，窗口大小 = w
图 5：滑动窗口注意力（左，w=4）的掩码模式——每个 token 只关注最近 4 个位置。 右图：通过堆叠多层，有效感受野线性增长。4 层 × w=4 = 感受野 16。

4.2 层间扩展感受野

虽然单层只看 w 个 token，但堆叠 L 层后，有效感受野扩展到 L × w。 Mistral 使用 w=4096、32 层，理论感受野为 131,072 token。 直觉上：第 1 层，token A 看到了 token B；第 2 层，A 通过 B 间接"看到"了 B 之前的信息； 逐层传递，远距离信息通过中间节点"接力"传播。

4.3 与 KV Cache 的结合

KV Cache 优化：滑动窗口意味着 KV Cache 有固定的上限 w， 而非随序列长度无限增长。Mistral 7B 的 KV Cache 固定为 4096 个 token 的缓存， 无论实际序列有多长——超出窗口的旧 K/V 直接丢弃。 这使得内存使用恒定，极大简化了长序列推理的内存管理。

✓ 优点

  • 计算复杂度降为 O(N · w)，w 远小于 N 时大幅加速
  • KV Cache 大小固定为 w，内存恒定
  • 与 FlashAttention 完美兼容
  • 通过层间堆叠保留长距离建模能力

✗ 缺点

  • 长距离信息传播变为间接，可能有信息损失
  • 需要精细选择窗口大小 w
  • 某些需要全局注意力的任务可能受影响

五、稀疏注意力（Sparse Attention）

5.1 动机

研究发现，在训练好的 Transformer 中，注意力权重矩阵通常是高度稀疏的—— 大部分权重接近于零，每个 token 实际上只"关注"少数几个其他 token。 稀疏注意力直接预定义或学习这种稀疏模式，跳过不重要的计算。

图 6：四种注意力模式对比。完全注意力计算全部 N×N 对；滑动窗口只算局部； 扩张注意力间隔采样；块稀疏结合局部+全局 token。

5.2 常见稀疏模式

1

Local（局部）

每个 token 只关注附近 w 个位置。即滑动窗口模式。适合语言建模中大部分为局部依赖的场景。

2

Strided / Dilated（扩张）

以固定步长采样远距离 token（如每隔 g 个位置关注一个）。用少量计算捕捉全局结构。 代表：Sparse Transformer (Child et al., 2019)。

3

Global + Local（全局+局部）

设置少量"全局 token"（如 [CLS] 或序列头部），它们可以关注和被关注所有位置； 其余 token 只做局部注意力。代表：BigBird, Longformer。

4

Learned Sparse（学习型稀疏）

模型动态决定每个 token 应该关注哪些位置。灵活性最高但实现复杂。 代表：Routing Transformer, Reformer (LSH hashing)。

实践限制：稀疏注意力在理论上很有吸引力，但在 GPU 上的实际加速往往不理想。 不规则的内存访问模式导致低效的 GPU 利用率，硬件更擅长处理密集矩阵运算。 因此，目前主流 LLM 更倾向于滑动窗口（规则稀疏，硬件友好） + FlashAttention（优化密集计算）的组合。

六、线性注意力（Linear Attention）

6.1 核心思想：改变矩阵乘法顺序

标准注意力的计算是 (Q @ KT) @ V，中间产生 N×N 矩阵。 线性注意力的核心观察是：如果去掉 Softmax，可以利用矩阵乘法结合律改变计算顺序为 Q @ (KT @ V)，中间矩阵变为 d×d（远小于 N×N）。

图 7：标准注意力（左）先算 Q@KT 得到 N×N 矩阵； 线性注意力（右）先算 KT@V 得到 d×d 矩阵，完全避免了 N×N 的瓶颈。

6.2 关键挑战：替代 Softmax

直接去掉 Softmax 会严重影响性能。解决方案是用核函数（kernel function） φ 来近似 Softmax 的效果：

StandardAttn: Softmax(QKT) V

LinearAttn: φ(Q) (φ(K)T V)    其中 φ 是特征映射函数

φ 的选择直接决定了近似质量，常见方案包括：

  • Performer：使用随机特征映射近似 Softmax 核
  • Linear Transformer：φ(x) = elu(x) + 1
  • RWKV：使用时间衰减的线性递推替代注意力
  • Mamba (SSM)：状态空间模型，输入依赖的选择机制

✓ 优点

  • 复杂度 O(N·d2)，当 d << N 时远快于 O(N2·d)
  • 可以用 RNN 形式实现——维护一个固定大小的"状态"，O(1) 推理每步
  • 天然支持无限长序列

✗ 缺点

  • 质量通常不如标准 Softmax 注意力，尤其在需要精确检索的任务上
  • 信息压缩为固定大小状态，可能丢失细节
  • 训练时难以并行化（RNN 形式）
趋势：2024-2025 年的前沿研究趋向于混合架构—— 大部分层使用线性注意力/SSM（高效），少数层使用标准 Softmax 注意力（高质量）， 兼顾效率和能力。代表：Jamba（Mamba + Transformer 混合）、Zamba、Hymba。

七、MLA —— 多头潜在注意力（Multi-head Latent Attention）

7.1 核心思想：低秩联合压缩 K 和 V

MLA（Multi-head Latent Attention）由 DeepSeek-V2（2024.05）首次提出， 后被 DeepSeek-V3 和 DeepSeek-R1 沿用。它采用了与 GQA/MQA 完全不同的压缩哲学： 不是减少 KV 头的数量，而是将 K 和 V 联合压缩到一个极小的潜在向量。

一句话理解：GQA 通过"让多个 Q 头共享 K/V"来节省内存； MLA 则通过"让所有 K 和 V 先压缩到一个小潜在向量 cKV， 使用时再投影回来"来节省内存。两者的思路截然不同——GQA 在头的维度压缩， MLA 在特征维度压缩。

7.2 数学定义

对于 KV 路径，MLA 引入一个潜在维度 dc（通常远小于 nh·dh）：

压缩（Down-projection）：
ctKV = ht · WDKV    其中 WDKV ∈ Rd × dc,   dc = 512

使用时解压（Up-projection）：
KtC = ctKV · WUK     Vt = ctKV · WUV

缓存的只有 cKV，不是 K 和 V！

同理，Query 路径也做低秩压缩（但 Q 不需要缓存，这里的目的是减少激活内存）：

ctQ = ht · WDQ  →  QtC = ctQ · WUQ

7.3 Decoupled RoPE：MLA 的关键技术难点

直接应用上述压缩会遇到一个致命问题： RoPE 与低秩压缩不兼容。

标准 RoPE 会对 Q 和 K 分别施加位置相关的旋转： Kt = RoPE(ht · WK, post)。 如果我们只缓存 cKV 然后在使用时计算 K = cKV · WUK， 旋转操作位置相关，无法合并到固定的 WUK 中—— 这意味着每个 token 需要单独旋转，不能利用"矩阵吸收"优化。

问题本质：RoPE 是位置相关的非线性操作，低秩压缩 + 上投影是位置无关的线性操作。 两者无法通过代数变换合并，导致必须为每个位置单独保存旋转后的完整 K， 失去了压缩的意义。

DeepSeek 的解决方案：解耦 RoPE（Decoupled RoPE）—— 将注意力分数分解为两部分：内容部分（无 RoPE）和 位置部分（小维度 RoPE）：

Kt = concat(KtC, KtR)
KtC = ctKV · WUK   (无 RoPE, 走低秩通路)
KtR = RoPE(ht · WKR, post)   (小维度 dhR=64)

同理 Q 也分为 QC 和 QR
  • 内容部分（KC）：不施加 RoPE，可以与 WUK 结合做矩阵吸收
  • 位置部分（KR）：施加 RoPE，但维度很小（dhR=64）， 且所有头共享（只需缓存 64 个数）
  • 缓存两部分：cKV（潜在向量，512 维）+ KR（共享 RoPE 键，64 维）
  • 注意力计算：QC · KCT + QR · KRT（两部分相加）

7.4 完整架构图

图 8：MLA 完整架构。Query 和 Key 都被拆分为内容部分（QC/KC，低秩压缩+上投影） 和 RoPE 部分（QR/KR，独立计算，后者跨所有头共享）。 KV Cache 只存储两样东西：潜在向量 cKV（512 维）和共享 RoPE 键 KR（64 维）， 总共 576 个值——相比标准 MHA 的 32768 值（128 头 × 128 维 × 2），压缩 56 倍。

7.5 Matrix Absorption：让 MLA 真正高效的魔法

仅仅压缩 KV Cache 是不够的——如果推理时每步都要执行 K = cKV · WUK 和 V = cKV · WUV 解压出完整的 K/V， 那计算量和标准 MHA 相同，只节省了内存，失去了速度优势。

DeepSeek 使用矩阵吸收（Matrix Absorption）技巧在推理阶段避免显式解压：

标准计算:   attention = softmax(QC · KCT) · V
    = softmax(QC · (cKV · WUK)T) · (cKV · WUV)

矩阵吸收：
= softmax((QC · WUK T) · cKV T) · (cKV · WUV)
= softmax(Q' · cKV T) · cKV · WUV
其中 Q' = QC · WUK T（提前吸收）

类似地，输出投影 WO 可以吸收 WUV：WO' = WUV · WO， 这样就完全避免了对 V 的显式计算。

图 9：矩阵吸收的威力。左图：朴素做法每步解压 K 和 V 回到 nh·dh=16384 维， 计算量与 MHA 相同；右图：通过矩阵吸收，注意力直接在 dc=512 维的潜在空间上计算， attention matmul 的维度降低 32 倍，同时受益于极小的 KV Cache。
矩阵吸收的效果： (1) 内存：KV Cache 只存 cKV 和 KR，大幅减少； (2) 计算：Attention matmul 从 [nh, 1, dh]×[nh, dh, t] 变为 [nh, 1, dc]×[1, dc, t]， 且所有头共享 cKV，实际是一个大 matmul； (3) 带宽：每步只需从 HBM 加载 cKV（小），而不是完整 K, V（大）， 解码延迟大幅降低。

7.9 MLA 的优缺点

✓ 优点

  • 极致的 KV Cache 压缩：优于 GQA，接近 MQA 但质量更高
  • Decode 加速：矩阵吸收使得 attention 计算也变小
  • 质量损失极小：接近完整 MHA 的性能
  • 支持长序列：小 KV Cache 使得超长上下文（128K+）在有限显存下可行

✗ 缺点

  • 实现复杂：Decoupled RoPE + 矩阵吸收 + 权重融合，工程代价高
  • 训练开销略大：引入额外的 down/up projection 矩阵
  • Prefill 阶段优势小：计算密集型，主要收益在 Decode
  • 框架支持有限：vLLM、SGLang 等需要专门实现，不如 GQA 普适

八、注意力架构变体：残差、门控与差分注意力

除了优化注意力的计算效率和内存效率，另一条同样重要的研究线路是改进 注意力输出与模型主干的交互方式——即注意力的残差连接结构、门控机制， 以及注意力本身的信噪比。这些改进直接影响模型的训练稳定性、 深度可扩展性和输出质量。

8.1 Attention Residuals（注意力残差连接）

残差连接（He et al., 2016）是深度网络训练的基石。在 Transformer 中， 注意力层和 FFN 层的输出都通过残差连接与输入相加：

output = x + Attn(Norm(x))

残差连接的作用有两个层面：

  • 梯度高速公路：梯度可以沿残差路径"绕过"注意力层直接回传， 避免深层网络中的梯度消失。没有残差连接，训练 80 层的 LLaMA-65B 几乎不可能。
  • 渐进式精化：每一层不是"替换"输入，而是在输入基础上"添加增量"。 模型的计算可以看作对初始表示的逐层精化。

Post-Norm vs Pre-Norm

归一化层的位置对训练稳定性有重要影响：

方案公式特点代表模型
Post-Norm
(原始 Transformer)		 Norm(x + Attn(x)) 性能上限略高，但训练不稳定，需要 warmup BERT, 原始 Transformer
Pre-Norm
(现代 LLM)		 x + Attn(Norm(x)) 训练稳定，无需复杂 warmup 策略 GPT-2/3, LLaMA, Mistral

Pre-Norm 的直觉：在注意力计算之前归一化输入，保证输入到 Q/K/V 投影的 向量数值范围可控。这对训练稳定性至关重要——如果输入值过大或过小， 注意力分数会出现极端值，导致 Softmax 退化和梯度爆炸。

8.2 Gated Attention（门控注意力）

标准残差连接中，注意力输出以固定权重 1.0 加到输入上。 门控注意力的思想是：让模型学习控制注意力输出的贡献比例。

Standard:   output = x + Attn(x)

Gated:   output = x + g(x) ⊗ Attn(x)

其中 g(x) = σ(x · Wg) ∈ (0, 1)d
图 11：三种注意力-残差交互方式。 标准残差（左）直接相加；门控注意力（中）通过学习的门控信号控制注意力贡献； α-残差门（右）使用可学习标量进行混合。

门控注意力的几种变体：

1

Sigmoid Gate（向量门控）

g = σ(x · Wg)，每个维度独立的 0-1 门控。 可以选择性地抑制注意力输出的某些维度。用于 PaLM、Gemma 等模型。

2

α-Residual Gate（标量门控）

output = (1-α) · x + α · Attn(x)， α 是每层/每头的可学习标量。初始化 α≈0 使模型在训练初期接近恒等映射。 用于 ReZero、Fixup 等深层训练技术。

3

Tanh Gate

g = tanh(x · Wg)，输出范围 (-1, 1)，允许反转注意力输出的符号。 比 Sigmoid gate 更灵活，但不保证非负。用于部分研究模型。

4

Gated Attention Unit (GAU)

将注意力和 FFN 合并为单一门控单元： output = (U ⊗ AV) Wo，其中 U 是门控路径，AV 是注意力路径。 减少层数的同时保持表达力。

为什么门控有效？ (1) 训练初期稳定性：门控初始化为接近 0，模型初期近似恒等映射，避免随机注意力带来的噪声； (2) 自适应深度：不同层可以学习不同的门控值，有的层贡献大、有的层几乎被"跳过"， 等价于模型自动决定有效深度； (3) 防止特征崩塌：门控限制了注意力输出的幅度，防止深层网络中所有 token 的表示 变得越来越相似（表示退化）。

8.3 Differential Attention（差分注意力）

Differential Attention（Ye et al., 2024, DIFF Transformer）提出了一种 全新的注意力降噪思路：用两组注意力的差来消除噪声。

DiffAttn(X) = (Softmax(Q1K1T/√d) - λ · Softmax(Q2K2T/√d)) · V

核心思想来自于信号处理中的差分放大器：两路信号中的共模噪声（common-mode noise） 在相减时被消除，只保留差模信号（有用信息）。

图 12：差分注意力的工作原理。输入被送入两组独立的注意力计算， 两组结果相减以消除共模噪声，λ 是可学习的缩放因子。

为什么有效？

  • 注意力噪声消除：标准 Softmax 注意力会在不相关的 token 上分配非零权重 （因为 Softmax 输出全正且和为 1）。这些"背景噪声"在两组注意力中是相似的， 相减后被大幅抑制。
  • 增强信号聚焦：真正重要的注意力模式在两组中也是相似的， 但它们的差异包含了更精炼的信息——就像立体声中左右声道的差异包含空间信息。
  • λ 的自适应：每个注意力头学习不同的 λ， 控制"差分程度"。λ 大表示强力降噪，λ 小表示保留更多原始注意力。
代价：差分注意力需要两倍的 Q/K 投影参数 （两组 Q 和两组 K），但 V 仍只需一组。总参数增量约 15-20%。 论文报告在同等参数预算下，DIFF Transformer 在语言建模、长上下文检索、幻觉抑制等任务上 均优于标准 Transformer。

8.4 跨层连接变体：Highway / DenseFormer / mHC

残差连接还有一类重要的演化方向：不再让每一层只看到前一层的输出 hl-1， 而是让每一层显式地访问更早的层。这些方法可以视为对"信息如何沿网络深度传播" 的不同回答。它们与 8.1-8.3 节的归一化/门控/差分注意力正交， 可以与之自由组合。

图 13：三种跨层连接变体的结构对比。
Highway（左）：每层动态门控混合 hl-1 与 f(hl-1)； DenseFormer（中）：每层用静态学习的标量加权聚合所有前驱层输出； mHC（右）：维护 m 条并行流，通过学习的混合矩阵在层间动态重组。

(a) Highway Networks（高速公路网络）

Highway Networks（Srivastava, Greff & Schmidhuber, 2015）是 深层网络中残差思想的早期探索之一，比 ResNet 早几个月提出。 它的核心是用逐元素的可学习门控来控制信息通过：

hl = (1 − gl) ⊙ hl-1 + gl ⊙ fl-1(hl-1)

其中 gl = σ(hl-1 · Wg) ∈ (0, 1)d
  • gl ≈ 0：该层近似恒等映射，让信号原样通过 → 适合训练初期
  • gl ≈ 1：完全使用变换后的结果 → 标准前馈层
  • gl 逐维独立：不同特征维度可以选择不同的"通过率"
历史地位：Highway 首次证明了"可学习的恒等通路"对训练超深网络至关重要。 ResNet 后来发现把门固定为 1（始终累加）反而效果更好，因为这给梯度提供了无衰减的反向路径。 但门控思想被后续的 LSTM、GRU、Gated Attention（8.2 节）、AttnRes 等持续继承。

(b) DenseFormer

DenseFormer（Pagliardini et al., 2024）是 DenseNet 思想在 Transformer 上的直接应用。 它打破了"每层只看 hl-1"的限制——每一层的输入都是所有前驱层输出的加权和：

hl = α0,l · h1 + Σi=1l-1 αi,l · fi(hi)

关键设计：

  • αi,l 是标量权重：每个 (i, l) 对一个学习参数，训练后固定， 不依赖输入（input-independent）
  • 每层 l 持有一个 [l] 维权重向量：总共 O(L2) 个标量参数，相对于模型主体可忽略
  • 每层都能直接"看见"早期 token embedding，缓解 PreNorm 稀释问题

DenseFormer 的优点是简单且无破坏性——只增加 O(L2) 参数， 主干结构不变。但它的核心局限是：权重是静态的， 一旦训练完成，所有 token 都使用相同的层间混合权重，无法根据上下文选择性地访问历史层。 这是后续 mHC 和 AttnRes 想要突破的瓶颈。

(c) mHC（multi-Hyper-Connections）

Hyper-Connections / mHC（Zhu et al., 2024; Xie et al., 2025）引入了一种全新的"多流"思路： 不再维护单一的隐藏状态序列，而是维护 m 条并行的隐藏状态流。

Hl = Hl-1 · Al   +   fl-1(Hl-1 · αl-1) · βl-1T

其中：Hl ∈ Rd×m（m 条流），Al ∈ Rm×m（学习的混合矩阵）， αl-1 ∈ Rm（输入聚合权重），βl-1 ∈ Rm（输出分发权重）

计算过程：

  1. 聚合输入：用 α 把 m 条流压缩为单一向量，作为 f 的输入
  2. 计算变换：执行一层 Attention 或 FFN
  3. 分发输出：用 β 把变换结果分散到 m 条流
  4. 跨流混合：通过 A 矩阵让 m 条流互相交换信息

这种"多流 + 跨流混合"的结构可以看作是标准残差的状态扩张—— 把单条状态 d 维扩张为 d×m 维，使早期信息可以在某条流中"被保留"而不被覆盖。 研究表明 m≈4 已经能带来显著的性能提升，且通信开销可控。

结构关系：从形式上看，mHC 是在深度维度上的"线性注意力"—— Al 矩阵起到"门控"作用，但它的权重是动态的（依赖输入）， 比 DenseFormer 的静态标量更灵活，但比 AttnRes 的 softmax 注意力简单。

统一视角：深度混合矩阵 M

所有这些方法都可以用一个统一的深度混合矩阵 M ∈ RL×L 描述， 其中 M[l, i] 表示第 l 层赋予第 i 层输出的权重：

hl = Σi=0l-1 M[l, i] · vi

其中 v0 = embedding, vi = fi(hi)
图 14：四种方案的深度混合矩阵 M 可视化（L=8）。
Standard Residual：所有元素 = 1 的下三角，等权累加； Highway：通过 carry-products 形成的衰减下三角； DenseFormer：稠密下三角，权重静态； AttnRes：稠密下三角，权重动态（softmax），呈现明显的对角线主导（局部性）和首列亮度（embedding sink）。

十、总结

注意力机制的优化围绕三条主线展开：

  1. 计算效率：从暴力计算所有 N×N 对（标准）， 到 IO 感知的分块计算（FlashAttention），到只计算局部（滑动窗口）， 到完全避免 N×N（线性注意力/SSM）。复杂度从 O(N2) 向 O(N) 逐步逼近。
  2. 内存效率：从每个头独立存储 KV（MHA），到组间共享（GQA）， 到全局共享（MQA），到低秩压缩（MLA）。KV Cache 从 100% 压缩到 5%。
  3. 质量与稳定性：Pre-Norm 残差保证训练稳定，门控注意力实现自适应深度， 差分注意力消除注意力噪声——这些架构改进使模型在同等参数下获得更高的输出质量。
当前最佳实践： FlashAttention 是计算层面的事实标准（精确且高效）， GQA 是内存层面的主流方案（平衡质量与效率）， 滑动窗口是长序列的实用选择， 门控残差和差分注意力提升训练稳定性和输出质量， 而 MLA 和混合架构（Transformer + SSM）代表着下一代的发展方向。
