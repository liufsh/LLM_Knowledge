大模型知识蒸馏详解

从 Hinton 经典蒸馏到 LLM 时代 —— 让小模型习得大模型的智慧
知识蒸馏 Logit 蒸馏 特征蒸馏 黑盒蒸馏 白盒蒸馏 DeepSeek-R1 模型压缩

引言：为什么需要知识蒸馏？

大语言模型（LLM）的参数规模从数十亿到数万亿不等，虽然能力强大，但部署成本极高： 一个 70B 模型推理需要多张高端 GPU，延迟高、吞吐低、能耗大。 知识蒸馏（Knowledge Distillation, KD）是一种模型压缩技术， 其核心思想是将大模型（教师模型）的知识迁移到小模型（学生模型）， 使小模型在参数量大幅减少的同时，尽可能保留大模型的能力。

图 1：知识蒸馏核心流程。教师模型的"暗知识"通过多种形式传递给学生模型，实现能力迁移。
本文聚焦： 本文将系统介绍知识蒸馏的核心原理（温度缩放、软标签、KL 散度），详细分类三种主流蒸馏范式（Logit 蒸馏、特征蒸馏、关系蒸馏）， 深入讲解 LLM 时代的白盒与黑盒蒸馏方法，并以 DistilBERT、TinyBERT、DeepSeek-R1 等主流模型为案例分析其实现方案。

一、经典知识蒸馏原理

1.1 Hinton 经典蒸馏框架（2015）

知识蒸馏最早由 Hinton 等人在 2015 年提出（Distilling the Knowledge in a Neural Network）。 其核心洞察是：训练好的模型不仅输出正确的类别标签（Hard Label）， 还在其 softmax 输出中蕴含了丰富的"暗知识"（Dark Knowledge）—— 即各类别之间的相似性关系。例如，一个图像分类模型判断某张图是"猫"时， 它也给"豹"分配了一个比"汽车"高得多的概率，这种类间关系就是暗知识。

暗知识的核心价值： Hard Label 只告诉学生"答案是什么"，而 Soft Label 告诉学生"哪些答案更接近正确答案"。 这种丰富的监督信号可以显著提升小模型的学习效率和泛化能力。 例如，教师模型输出 [猫: 0.7, 豹: 0.2, 狗: 0.08, 汽车: 0.02] 比 [猫: 1, 其他: 0] 包含更多信息。

1.2 温度缩放（Temperature Scaling）

标准 softmax 的输出通常非常"尖锐"（一个类别的概率趋近于 1，其余趋近于 0），这不利于暗知识的传递。 Hinton 引入了温度参数 T 来"软化"概率分布：

qi = exp(zi / T) / ∑j exp(zj / T)

其中 zi 是模型输出的 logit（未经 softmax 的原始值），T 是温度参数。

温度 T效果说明
T = 1标准 softmax概率分布尖锐，信息量小
T > 1分布更平滑暗知识被放大，类间差异更明显
T → ∞趋近均匀分布所有类别概率相近，信息被稀释
T < 1分布更尖锐趋近于 one-hot，暗知识丢失
实践经验：温度 T 通常取 2~20 之间。T 太小则暗知识不足，T 太大则信号被噪声淹没。 Hinton 原文建议在教师模型置信度较高时使用较大的 T（如 T=20），在不确定性较大时使用较小的 T（如 T=2~5）。 LLM 蒸馏中 T 通常取 1~3。

1.3 蒸馏损失函数

经典蒸馏使用两个损失函数的加权组合：

Ltotal = α · Lhard + (1 − α) · T² · Lsoft

① Hard Loss（硬标签损失）

学生模型输出与真实标签之间的交叉熵损失：

Lhard = − ∑i yi · log piS(T=1)

② Soft Loss（软标签损失）

学生模型与教师模型在温度 T 下的软标签之间的 KL 散度：

Lsoft = KL(pT(T) ∥ pS(T)) = ∑i piT(T) · log( piT(T) / piS(T) )

其中 pT 和 pS 分别为教师和学生在温度 T 下的 softmax 输出。 T² 是一个补偿因子——当温度 T 增大时，softmax 后梯度的量级会缩小约 1/T² 倍，乘以 T² 可以恢复梯度量级。 α 是超参数，通常取 0.1~0.5，表示硬标签和软标签的权重平衡。

图 2：经典蒸馏损失函数结构。Soft Loss 传递暗知识，Hard Loss 保持精度，两者加权组合。

二、知识蒸馏的三大范式

根据从教师模型中提取知识的层次和方式不同，知识蒸馏可以分为三大范式： 基于 Logit 的蒸馏、基于特征的蒸馏、基于关系的蒸馏。

2.1 基于 Logit 的蒸馏（Logit-based Distillation）

这是最经典、最简单的蒸馏形式，直接让学生模型的输出分布去匹配教师模型的输出分布。 前述 Hinton 的方法就属于此类。

1

标准 KL 蒸馏

直接最小化教师和学生 softmax 输出之间的 KL 散度。简单高效，适用于绝大多数场景。

2

Top-K Logit 蒸馏

只对教师模型 Top-K 概率最高的 token 进行蒸馏，大幅减少 LLM 场景下的计算量和存储开销。

3

Reverse KL

最小化 KL(pS ∥ pT)，鼓励学生集中在教师的主要模式上，避免分散注意力到低概率区域（mode-seeking）。

4

Sequence-level KD

在序列（句子）层面做蒸馏，如 Kim & Rush (2016)，用教师生成的翻译作为训练数据。

✅ 优势

  • 实现简单，只需教师输出的 logits
  • 不要求教师和学生架构相同
  • 计算开销小，易于大规模应用
  • 通用性强，适用于分类和生成任务

⚠️ 局限

  • 只利用了最终输出层信息
  • 无法传递中间层的表示知识
  • 当教师和学生能力差距过大时效果下降
  • 对于 LLM，词表巨大导致 KL 计算开销高

2.2 基于特征的蒸馏（Feature-based Distillation）

特征蒸馏不仅匹配最终输出，还匹配教师模型中间层的隐藏表示（Hidden States / Attention Maps）。 这种方式传递了更丰富的结构化知识，代表工作有 FitNets（2014）、TinyBERT（2019）等。

Lfeature = ∑l∈S MSE( f(HlS), g(Hm(l)T) )

其中 HlS 和 Hm(l)T 分别是学生第 l 层和教师对应层的隐藏状态， f 和 g 是可学习的映射函数（因为学生和教师的隐藏维度通常不同）。

层映射策略：教师模型有 N 层，学生模型有 M 层（M < N），如何将教师的层映射到学生的层？ 常见策略包括：
均匀映射：将教师的 N 层均匀分配给学生的 M 层，如教师 12 层 → 学生 4 层：{3→1, 6→2, 9→3, 12→4}。
首尾 + 均匀：固定首尾层映射，中间层均匀分配。
可学习映射：使用注意力机制自动学习最优的层对应关系。

2.3 基于关系的蒸馏（Relation-based Distillation）

关系蒸馏关注的不是单个样本的输出或特征，而是样本之间的关系结构。 教师模型中样本之间的相似性模式（如哪些样本在嵌入空间中更接近）本身就是一种重要的结构化知识。

1

PKT（概率知识迁移）

匹配教师和学生嵌入空间中样本对之间的余弦相似性分布，传递空间结构信息。

2

RKD（关系知识蒸馏）

匹配样本对之间的距离关系（二阶）和角度关系（三阶），不依赖于特征维度的对齐。

3

CRD（对比表示蒸馏）

使用对比学习目标，让学生学习与教师一致的表示空间结构。对特征维度差异更鲁棒。

4

注意力迁移

匹配教师和学生的注意力图（Attention Maps），让学生学会"关注相同的位置"。

三、LLM 时代的蒸馏方法

在 LLM 时代，模型规模从亿级跃升到千亿级，蒸馏方法也发生了根本性变化。 根据是否能访问教师模型内部参数，LLM 蒸馏分为白盒蒸馏和黑盒蒸馏两大类。

图 3：LLM 蒸馏方法分类体系。白盒蒸馏信息丰富但要求模型开源，黑盒蒸馏灵活通用但信号有限。

3.1 白盒蒸馏（White-box Distillation）

白盒蒸馏要求可以访问教师模型的全部内部信息（权重、logits、隐藏状态、注意力矩阵等）。 这种方式信息利用率最高，但前提是教师模型必须是开源的。

核心挑战：词表大小

LLM 的词表通常有 32K~150K 个 token，每一步生成都需要计算完整词表上的概率分布。 传统的全词表 KL 散度计算在 LLM 场景下开销极大。因此出现了多种优化方案：

  • Top-K Logit 蒸馏：只对概率最高的 K 个 token 计算 KL 散度，K 通常取 10~100
  • MiniLLM (2023)：使用 Reverse KL 替代 Forward KL，避免学生对低概率区域过度拟合
  • GKD (2023)：Generalized KD，用学生自己生成的序列（on-policy）来计算蒸馏损失，缓解 exposure bias
  • DistiLLM (2024)：结合 Skew KL + 自适应 off-policy 蒸馏，在大词表场景下更稳定

3.2 黑盒蒸馏（Black-box Distillation）

黑盒蒸馏只能获取教师模型的文本输出（不能获取 logits 或中间层信息）， 通常是通过 API 调用大模型（如 GPT-4、Claude）来生成训练数据，然后用这些数据训练小模型。 这是当前 LLM 蒸馏中最广泛采用的方法。

黑盒蒸馏的三种形式

1

数据增强蒸馏

利用教师模型生成大量高质量指令-回复对，学生模型在这些数据上做 SFT。 代表：Alpaca（Self-Instruct）、Vicuna（ShareGPT 数据）、WizardLM（Evol-Instruct）。

2

思维链蒸馏（CoT Distillation）

让教师模型生成含有详细推理过程（Chain-of-Thought）的回复，学生模型学习模仿推理链。 代表：Orca、DeepSeek-R1 蒸馏版。

3

反馈/评估蒸馏

教师模型作为评判者（Judge），对学生模型的输出进行评分和反馈，学生根据反馈迭代优化。 代表：Self-Instruct、Constitutional AI 中的部分思想。

4

能力蒸馏

针对特定能力（代码、数学、推理）生成专门的训练数据。 代表：WizardCoder（代码）、WizardMath（数学）、MAmmoTH（数学推理）。

为什么黑盒蒸馏在 LLM 时代如此流行？
① 最强的教师模型（GPT-4、Claude）都是闭源的，只能通过 API 访问；
② 黑盒蒸馏本质上是数据工程，不需要复杂的训练框架修改；
③ 实践证明，高质量的教师生成数据可以极大提升小模型性能。

4.2 选择学生架构

学生模型的架构选择需要在性能和效率之间权衡：

  • 同架构缩小：最常见，如将 LLaMA-70B → LLaMA-7B，减少层数/隐藏维度/注意力头数
  • 跨架构蒸馏：如从 Transformer → 线性注意力模型（Mamba），需要更精心的蒸馏设计
  • 学生初始化策略：可以从教师模型的部分层初始化（层选择/层合并），也可以随机初始化
能力差距问题（Capacity Gap）： 研究发现，当教师和学生的能力差距过大时，直接蒸馏效果反而不好。解决方案包括：
① 渐进式蒸馏（Progressive Distillation）：70B → 30B → 13B → 7B，逐级蒸馏；
② 教师助手蒸馏（Teacher Assistant, TAKD）：引入中等大小的"助教"模型做中介。

4.3 准备蒸馏数据

1

原始训练数据

使用教师模型原始的预训练/微调数据，让教师在这些数据上生成 logits 或文本输出。适合白盒蒸馏。

2

教师生成数据

让教师根据种子指令生成大量新的训练样本，包含回答和推理过程。适合黑盒蒸馏。

3

混合数据

将真实数据和教师生成数据按比例混合，通常能获得最好效果。比例需要调参。

4

针对性数据

分析学生弱项，针对性地让教师生成强化训练数据（如学生数学弱，则增加数学推理数据）。

4.4 设计蒸馏策略

策略具体方法适用场景
离线蒸馏 预先用教师模型对所有数据生成 logits/文本并缓存，学生训练时直接读取 教师推理成本高、需要反复训练学生

五、主流蒸馏模型实现方案

5.1 DistilBERT（2019, Hugging Face）

DistilBERT 是最经典的 NLP 蒸馏实践之一，将 BERT-base（110M）蒸馏为 66M 参数的小模型， 保留了 97% 的性能，推理速度提升 60%。

核心设计

  • 架构：从 BERT-base 的 12 层减少为 6 层，保持隐藏维度不变（768）
  • 初始化：从教师模型中每隔一层抽取权重来初始化学生（第 1、3、5、7、9、11 层）
  • 训练目标：三重损失 = Soft Label Loss + Hard Label (MLM) Loss + Cosine Embedding Loss
  • 数据：使用与 BERT 相同的预训练数据（英文 Wikipedia + BookCorpus）
LDistilBERT = α · Lce + β · Lmlm + γ · Lcos
DistilBERT 的关键创新： 加入了 Cosine Embedding Loss 来对齐教师和学生的隐藏表示方向，这弥补了纯 Logit 蒸馏在中间层信息利用上的不足。 实验显示 Cosine Loss 约带来 1-2% 的额外性能提升。

5.3 MiniLM（2020, 微软）

MiniLM 发现不需要对所有中间层做蒸馏，只需对教师模型最后一层的自注意力关系进行蒸馏， 就能取得很好的效果，大幅简化了蒸馏流程。

核心思想：Value-Relation 蒸馏

MiniLM 提出了 Value-Value Relation 蒸馏：不直接对齐隐藏状态（维度可能不同）， 而是对齐 Value 向量之间的点积关系矩阵（维度无关），避免了投影层的引入。

LMiniLM = KL( softmax(VT · VT⊤ / √d) ∥ softmax(VS · VS⊤ / √d) )

MiniLMv2 改进

  • 将蒸馏扩展到多头注意力关系，每个头分别蒸馏后加权融合
  • 支持教师和学生不同层数、不同维度、不同注意力头数
  • 引入了多教师蒸馏：可以从多个不同大小的教师模型联合蒸馏

5.4 Alpaca（2023, 斯坦福）—— 黑盒蒸馏开创者

Alpaca 开创了"用强大 API 模型生成数据 → 微调开源小模型"的黑盒蒸馏范式， 仅花费不到 600 美元（API 费用）就让 LLaMA-7B 获得了接近 GPT-3.5 的对话能力。

input：可选的输入内容（如需要翻译的句子）
output：GPT-3.5 生成的高质量回答

5.5 Vicuna（2023, LMSYS）

Vicuna-13B 使用从 ShareGPT 平台收集的约 70K 条用户与 ChatGPT 的多轮对话数据， 对 LLaMA-13B 进行微调。Vicuna 在 GPT-4 作为评估者的打分中达到了 ChatGPT 92% 的质量。

5.6 Orca / Orca 2（2023, 微软）—— 推理过程蒸馏

Orca 的核心创新在于：不仅蒸馏教师模型的回答结果，还蒸馏其推理过程。 通过在 System Prompt 中要求 GPT-4 "逐步思考并解释推理过程"，生成包含详细推理链的训练数据。

核心方法：Explanation Tuning

  • System Prompt 要求教师"explain step by step"、"think carefully"
  • 收集教师的完整推理过程（而不仅仅是最终答案）
  • 数据包含：System Prompt + 用户问题 + 教师的推理过程 + 最终答案
  • 学生在 SFT 时同时学习"如何思考"和"如何回答"
Orca 2 的改进： Orca 2 发现小模型不应该盲目模仿大模型的推理策略。对于简单问题，大模型可能用复杂推理； 而小模型应该学会选择合适的推理策略（直接回答 vs. 逐步推理 vs. 编程求解）。 Orca 2 因此引入了"Cautious Reasoning"机制，让小模型学会判断何时需要深度推理。

5.7 DeepSeek-R1 蒸馏版（2025, DeepSeek）

DeepSeek-R1 是推理蒸馏领域的里程碑式工作。它首先通过 RL（强化学习）训练出一个强大的推理模型 DeepSeek-R1（671B MoE）， 然后将其推理能力蒸馏到一系列更小的模型中（1.5B ~ 70B）。

蒸馏方案

图 4：DeepSeek-R1 蒸馏流程。通过 800K 高质量推理数据，将 671B 模型的推理能力蒸馏到 1.5B~70B 的小模型中。

核心技术细节

  • 数据生成：使用 DeepSeek-R1 在数学、代码、科学、逻辑等领域生成约 800K 条高质量推理样本
  • 数据格式：每条数据包含 <think> 标签内的长推理链 + 最终答案
  • 训练方式：纯 SFT（监督微调），不使用额外的 RL 训练
  • 基座选择：选用 Qwen2.5 和 LLaMA-3 系列作为基座模型，利用其良好的预训练基础
  • 关键发现：蒸馏效果 > 小模型直接 RL 训练。纯 SFT 蒸馏的 R1-Distill-Qwen-7B 已超越花大量算力 RL 训练的同等规模模型
DeepSeek-R1 蒸馏的里程碑意义： ① 证明了推理能力可以通过纯 SFT 蒸馏有效迁移，不需要对小模型做 RL；
② 1.5B 的蒸馏模型就能在 AIME 上超越 GPT-4o，展示了蒸馏的巨大潜力；
③ 开源了全部蒸馏模型（1.5B~70B），极大推动了社区研究。

六、蒸馏中的高级技术

6.1 渐进式蒸馏（Progressive Distillation）

当教师和学生的能力差距过大时，直接蒸馏效果不佳。渐进式蒸馏通过构建一条蒸馏链， 让知识沿着"大模型 → 中模型 → 小模型"的路径逐步传递。

→
1.5B 学生

6.2 自蒸馏（Self-Distillation）

模型作为自己的教师进行蒸馏，常见形式包括：

  • 深层 → 浅层：模型深层的输出作为浅层的蒸馏目标
  • Born-Again Networks：先训练一个模型，然后用它做教师训练一个相同架构的新模型，反复迭代
  • R-Drop：同一模型两次前向传播（dropout 不同），最小化两次输出的 KL 散度
  • DPO 中的自蒸馏：用模型自身的旧版本作为参考模型

6.3 多教师蒸馏（Multi-Teacher Distillation）

将多个不同教师模型的知识联合蒸馏到一个学生模型中，常用于融合多个专家模型的优势。

Lmulti = ∑k=1K wk · KL(pTk ∥ pS)

权重 wk 可以固定（如均匀分配），也可以根据每个教师在不同任务上的表现动态调整。

6.4 蒸馏 + 剪枝/量化联合优化

蒸馏可以与其他模型压缩技术联合使用，进一步提高效率：

1

蒸馏 + 结构化剪枝

先对教师模型进行结构化剪枝（删除不重要的注意力头、FFN 中间维度），然后用蒸馏恢复性能。 代表：Llama-3.2 (1B/3B) = Llama-3.1 pruning + distillation。

2

蒸馏 + 量化

先蒸馏到小模型，再对小模型做 INT4/INT8 量化。或在蒸馏过程中加入量化感知训练（QAT）。 可实现 10~100 倍的总压缩率。

3

蒸馏 + LoRA

使用 LoRA 低秩适配来高效训练学生模型，减少蒸馏过程中的可训练参数量。 在资源受限场景下非常实用。

4

蒸馏 + 架构搜索

用 NAS（神经架构搜索）自动找到最优的学生架构，再用蒸馏训练。 如 AutoTinyBERT 自动搜索最优的层数/维度/头数配置。

七、LLM 蒸馏中的 KL 散度变体

在 LLM 蒸馏中，KL 散度的方向选择对蒸馏效果有显著影响。三种主要变体各有优劣：

7.1 Forward KL（标准 KL）

LFKL = KL(pT ∥ pS) = ∑ pT(x) log( pT(x) / pS(x) )

特性：Mode-covering。学生被迫覆盖教师分布的所有模式。 当教师在某个 token 上有非零概率时，学生也必须给予非零概率，否则 KL 趋近无穷。 这导致学生分布更"分散"，可能在低概率区域浪费容量。

7.2 Reverse KL

LRKL = KL(pS ∥ pT) = ∑ pS(x) log( pS(x) / pT(x) )

特性：Mode-seeking。学生倾向于集中在教师概率最高的区域。 当学生在某个 token 上有高概率但教师概率为零时，惩罚非常大。 这使得学生更"集中"和"精确"，但可能错过教师分布的一些次要模式。

7.3 Skew KL（偏斜 KL）

LSKL = KL(pT ∥ α · pT + (1−α) · pS)

特性：在 Forward KL 和 Reverse KL 之间做插值，α 控制平衡点。 更稳定，避免了两种极端情况。DistiLLM 采用此方案。

方法行为模式优势劣势适用场景
Forward KLMode-covering 覆盖全面、不会遗漏分散注意力、低效 通用蒸馏、分类任务
Reverse KLMode-seeking 生成质量高、更集中可能丢失多样性 生成任务 (MiniLLM)
Skew KL可调折中 稳定、灵活多一个超参数 大词表 LLM (DistiLLM)

8.2 最佳实践总结

1

数据质量 > 数据数量

DeepSeek-R1 用 800K 高质量数据就超越了百万级普通数据的效果。Phi 系列用"教科书级"数据让 1.3B 模型超越 10B+ 模型。

2

控制能力差距

教师和学生的参数比建议在 3x~10x。差距过大时采用渐进式蒸馏或引入教师助手。

3

选择合适的蒸馏层次

简单任务 Logit 蒸馏够用；复杂推理任务考虑 CoT 蒸馏；同架构族内优先考虑特征蒸馏。

4

学生初始化策略很重要

从教师模型中抽取部分层来初始化学生（如 DistilBERT），通常比随机初始化好 2-5 个百分点。

5

蒸馏 + RL 可以叠加

先蒸馏获得基础能力，再用 RL（如 GRPO）进一步提升。DeepSeek-R1 发现蒸馏 + RL 效果 > 单独蒸馏。

6

注意版权和合规

使用闭源模型 API 生成蒸馏数据时，需遵守服务条款。部分模型（如 GPT-4）明确禁止用于训练竞品模型。

九、前沿趋势与未来方向

1

推理能力蒸馏

以 DeepSeek-R1 为代表，通过蒸馏 o1-style 推理链让小模型掌握深度推理能力，是当前最热门的研究方向。

2

跨模态蒸馏

将多模态大模型（如 GPT-4V）的视觉理解能力蒸馏到更小的视觉语言模型中，降低多模态推理成本。

3

端侧部署蒸馏

针对手机、边缘设备，将大模型蒸馏到 1B~3B 量级并结合量化，实现端侧离线推理。如 Gemma-2-2B、Llama-3.2-1B。

4

Speculative Decoding 蒸馏

训练一个小型草稿模型（Draft Model），用于推测解码加速大模型推理。本质上也是一种面向推理效率的蒸馏。

5

强化学习 + 蒸馏协同

先 RL 训练教师、再蒸馏学生，或蒸馏后继续 RL 微调。DeepSeek-R1 的成功证明了这条路线的价值。

6

MoE 蒸馏到 Dense

将 MoE（混合专家）模型的知识蒸馏到 Dense 模型中，避免 MoE 的路由开销和负载均衡问题。

总结

图 5：知识蒸馏技术从 2015 年至今的演进路线。从白盒中间层对齐到黑盒推理链蒸馏，技术不断演化。
核心结论：
① 知识蒸馏是大模型"民主化"的关键技术，让强大的 AI 能力能够在更低成本下获得；
② LLM 时代的蒸馏已从"对齐输出分布"演进为"迁移推理能力"，黑盒 CoT 蒸馏成为主流；
③ 数据质量是蒸馏成功的第一要素——DeepSeek-R1 的 800K 精选数据胜过百万级普通数据；
④ 蒸馏与 RL、剪枝、量化的组合使用，是实现端侧部署的关键路径；
⑤ 未来方向：推理能力蒸馏、跨模态蒸馏、MoE→Dense 蒸馏将是重点。
