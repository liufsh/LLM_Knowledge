引言：Qwen3.5 系列与 27B 模型定位

Qwen3.5 系列是阿里巴巴通义实验室 2026 年推出的新一代基础模型家族，相比 Qwen3 系列， 其在多模态学习、架构效率、强化学习规模化、全球语言覆盖四个维度均实现显著突破。 系列包含多个规格：旗舰 Qwen3.5-122B-A10B（MoE）、紧凑型 Qwen3.5-27B（Dense）、轻量级 Qwen3.5-35B-A3B（MoE）等。

其中 Qwen3.5-27B 是一款参数量 27B 的 Dense 因果语言模型（带视觉编码器）， 采用混合线性注意力 + 全注意力的全新架构 —— 在 64 层结构中以 3:1 比例交错排列 Gated DeltaNet（线性注意力）与 Gated Attention（全注意力），从根本上降低长上下文的计算与显存开销。 模型原生支持 262,144 tokens 上下文，并可扩展至约 1,010,000 tokens。

核心创新主线： Qwen3.5-27B 的关键设计在于"用线性注意力做绝大部分工作，用全注意力做关键检索"—— 每 4 层中 3 层为 O(L) 复杂度的 Gated DeltaNet，仅 1 层为 O(L²) 的 Gated Attention（GQA + RoPE）， 在保持全注意力建模能力的同时，将整体计算量、KV 缓存与解码延迟显著降低。

一、背景知识

1.1 线性注意力与标准注意力的对比

标准 Softmax 注意力的核心公式为 Attention(Q,K,V) = Softmax(QKT/√d) V， 其计算复杂度为 O(L²d)，其中 L 为序列长度、d 为头维度。当 L 增大到数十万甚至百万时， 二次方的计算量与 O(Lhd) 的 KV 缓存成为推理效率的关键瓶颈。

线性注意力（Linear Attention）的核心思路是去掉 Softmax，将注意力写为 LinearAttn(Q,K,V) = φ(Q) (φ(K)TV)， 其中 φ 为某种特征映射。通过先计算 φ(K)TV（d×d 矩阵）， 再乘以 φ(Q)，可将复杂度降为 O(Ld²)。更重要的是，线性注意力可写为 RNN 形式：

St = St-1 + φ(kt) vtT ,   ot = φ(qt) St

其中 St ∈ Rd×d 为递推状态矩阵。在自回归解码时可以 O(1) 地生成每个 token， 无需维护完整 KV 缓存。但简单线性注意力的表达力往往弱于 Softmax 注意力—— 因为 St 是无选择地累加所有历史信息，缺乏"遗忘"机制。

1.2 Delta Rule 与 DeltaNet

DeltaNet 源自经典联想记忆中的 Delta Rule（增量学习规则）。 与简单线性注意力"只累加不遗忘"不同，Delta Rule 在每一步先从状态矩阵中 擦除当前键已关联的旧值，再写入新的键-值关联，使状态矩阵具有"选择性遗忘"能力：

St = St-1 - βt kt (ktT St-1) + βt kt vtT = St-1 + βt kt (vt - ktT St-1)T

其中 βt ∈ (0,1] 为可学习的更新门控。直觉上：如果 kt 对应的旧值 ktTSt-1 已经等于新值 vt， 则 Δ 项为零，不作无谓更新；否则按差值精确修正。这相当于一种 误差驱动的在线学习，使得状态矩阵能在有限容量下不断更新最相关的信息。

图 1：简单线性注意力 vs DeltaNet 的状态更新对比。DeltaNet 的 Delta Rule 赋予模型"选择性遗忘"能力。

1.3 Grouped-Query Attention（GQA）

GQA 是标准多头注意力（MHA）和多查询注意力（MQA）之间的折中方案。在 MHA 中每个 Q 头对应独立的 K/V 头， 而 MQA 所有 Q 头共享同一组 K/V。GQA 将 Q 头分成若干组，组内共享 K/V 头， 在减少 KV 缓存的同时保持较好的模型质量。

Qwen3.5-27B 的 Gated Attention 层使用 24 个 Q 头 / 4 个 KV 头（GQA-6 分组比）， 每组 6 个 Q 头共享 1 组 KV，头维度 256，并在 64 维上施加 RoPE（partial_rotary_factor = 0.25， 即 25% 的头维度使用旋转位置编码），其余维度不加位置编码。

1.4 旋转位置编码（RoPE）

RoPE 通过将位置信息编码为旋转矩阵，在 Q/K 向量的各维度对上施加依赖于位置差的旋转角度。 其核心公式为：

RoPE(xm, m) = xm ⊗ eimθ,   θi = Θ-2i/d,   其中 Θ 为频率基数

Qwen3.5-27B 采用 rope_theta = 10,000,000（一千万），远高于标准值 10,000， 这使得低频旋转角变得更小，有助于外推到更长序列。此外使用 partial_rotary_factor = 0.25，仅在头维度的前 25%（64 维）施加 RoPE， 其余 192 维保持位置无关，这种 Partial RoPE 设计有助于在位置编码与内容特征之间取得平衡。 对视觉特征还使用了 多分辨率 RoPE（M-RoPE）， 将 RoPE 维度分为 [11, 11, 10] 三段分别编码空间和时间位置。

1.5 Multi-Token Prediction（MTP）

传统自回归语言模型每步仅预测下一个 token。MTP（多步/多 token 预测） 让模型同时预测未来多个 token，作为辅助训练目标。Qwen3.5-27B 配置 mtp_num_hidden_layers = 1，即在主网络之上额外增加 1 层预测头， 用于预测下一步的 token，训练时产生更丰富的梯度信号，加速收敛并提升模型规划能力。 在推理时，MTP 预测头还可用于投机解码（Speculative Decoding）， 即先用 MTP 头快速猜测多个后续 token，再由主网络一次性验证，显著提升解码吞吐量。

二、整体架构详解

2.1 Hybrid 3:1 层布局

Qwen3.5-27B 的 64 层 Transformer 按严格的 3:1 模式 排列：

16 × ( 3 × (Gated DeltaNet → FFN) → 1 × (Gated Attention → FFN) )

即每 4 层为一个重复单元（Block）：前 3 层使用线性注意力（Gated DeltaNet）， 第 4 层使用全注意力（Gated Attention）。共 16 个这样的 Block 构成完整模型。 这种设计的核心直觉是：

  • Gated DeltaNet 层（第 1/2/3 层）：承担信息的增量压缩与局部推理， 以 O(L) 复杂度高效处理长序列，但其线性递推本质决定了无法做精确的全序列检索。
  • Gated Attention 层（第 4 层）：以 O(L²) 复杂度提供全序列的精确注意力， 负责远程依赖捕获、精确信息检索等线性注意力难以胜任的任务。

通过将 75% 的层替换为线性注意力，模型的整体推理 FLOPs 和 KV 缓存大幅降低， 同时保留 25% 的全注意力层保障精确检索能力。

图 2：Qwen3.5-27B 整体架构。64 层按 3:1 比例交替排列 Gated DeltaNet 与 Gated Attention，每层后跟 SwiGLU FFN。

三、Gated DeltaNet 线性注意力详解

3.1 核心原理

Qwen3.5-27B 中的 Gated DeltaNet 是对基础 DeltaNet 的增强版本，在 Delta Rule 递推基础上增加了 输入门控和短卷积，整体计算流程为：

  1. 短卷积（Conv1D, kernel=4）：对输入隐状态先施加核大小为 4 的因果卷积， 捕获局部 n-gram 模式，弥补纯递推模型对局部模式感知不足的缺陷。
  2. QKV 投影：将卷积后的特征分别投影为 Q（16 头×128 维）、K（16 头×128 维）、 V（48 头×128 维）。注意 V 的头数是 QK 的 3 倍，这意味着每个 QK 头负责更新 3 个 V 头的状态矩阵， 从而增大模型的信息容量。
  3. 门控生成：生成可学习的标量门控 βt（更新强度）和 αt（遗忘强度），控制状态矩阵的更新与衰减。
  4. Delta Rule 状态更新： St = αt St-1 + βt kt(vt - ktTSt-1)T
  5. 输出计算：ot = qtT St， 并通过输出门控（output gate）调制最终结果。
图 3：Gated DeltaNet 单层计算流程。短卷积捕获局部模式，QKV 投影后通过 Delta Rule 更新状态矩阵，门控调制输出。

3.2 V/QK 头数不对称设计

一个引人注目的设计是 DeltaNet 层中 V 头数（48）是 QK 头数（16）的 3 倍。 这意味着每个 QK 头的键空间对应 3 个独立的值空间，即同一个键可以关联 3 组不同的值向量。 这种不对称设计显著增大了状态矩阵的总信息容量（16 × 3 = 48 个 128×128 状态矩阵）， 而键的查询/匹配操作只需在 16 个头上进行，节省了计算量。

直觉理解： 可将 QK 头看作"索引系统"，V 头看作"存储系统"。 使用较少的索引头（16）进行高效匹配，但每个索引下挂载更多的存储头（×3）， 总存储容量 = 48 × 128 × 128 ≈ 786K 参数 / 层，远大于同参数量的标准设计。

3.3 训练与推理的双模式

DeltaNet 的 Delta Rule 递推本质上是顺序操作，但在训练时可利用分块并行（Chunkwise Parallel） 算法加速：将序列分为固定大小的块，块内使用并行矩阵乘法计算，块间传递递推状态。 这使得训练效率接近标准 Transformer，同时保留了推理时 O(1) 状态更新的优势。

在推理解码时，DeltaNet 层只需维护一个 128×128 的状态矩阵（每个 QK 头）， 无需存储完整的 KV 缓存。而全注意力层仍需 KV 缓存， 但由于只有 16/64 = 25% 的层是全注意力，KV 缓存需求降低约 75%。

四、Gated Attention 全注意力层详解

4.1 GQA 配置

Gated Attention 层使用 Grouped-Query Attention（GQA） 配置： 24 个查询头、4 个 KV 头，分组比 6:1。每组 6 个 Q 头共享 1 组 KV 头的键值投影。 头维度为 256，总注意力隐维度 = 24 × 256 = 6144，大于隐藏层维度 5120， 通过输入/输出投影在 5120 ↔ 6144 之间变换。

4.2 Partial RoPE

在头维度 256 中，仅前 64 维（25%）施加旋转位置编码（RoPE）， 其余 192 维保持位置无关。这种 Partial RoPE 设计的优势在于：

  • 位置编码维度较小，不会过度约束注意力的语义匹配能力
  • 降低了 RoPE 频率外推在高维度上的不稳定性，有利于长上下文扩展
  • 192 维的非位置特征可以自由学习纯内容匹配模式

4.3 输出门控（Output Gate）

配置 attn_output_gate = true 表示注意力输出 o 在投影回残差路径之前， 要乘以一个由输入生成的门控标量 g：output = g ⊙ Wo · o。 这为模型提供了一种自适应机制来控制每层注意力对残差流的贡献强度， 在训练稳定性和表达力之间取得平衡。DeltaNet 层也同样使用输出门控。

5.2 早期融合策略

Qwen3.5 系列采用早期融合（Early Fusion）训练策略， 在预训练阶段即使用混合图文 token 序列训练模型。视觉编码器将图像/视频编码为视觉 token， 通过线性投影对齐到语言模型的 5120 维空间后，与文本 token 拼接成统一序列输入模型。 这种端到端训练方式使得多模态训练效率接近纯文本训练的 100%， 且视觉语言能力与纯语言能力实现"代际平齐"——即 Qwen3.5 的语言能力不弱于 Qwen3， 同时超越了 Qwen3-VL 的视觉理解能力。

视觉 token 使用特殊标记界定：<|vision_start|> 和 <|vision_end|>，图像使用 <|image_pad|>， 视频使用 <|video_pad|> 作为占位符。 对于视觉 token 的位置编码，使用多分辨率 RoPE（M-RoPE）， 将 RoPE 维度 64 拆分为 [11, 11, 10] 三段分别编码 H, W, T 三个空间-时间维度。

六、效率分析：混合架构 vs 全注意力

6.1 计算复杂度对比

在序列长度 L 下，纯 Softmax Transformer 的注意力计算量为 O(L²hd)（h 为头数，d 为头维度）。 Qwen3.5-27B 的混合架构中：

  • 48 层 DeltaNet：每层 O(Ld²) 的递推计算（训练时分块并行化）， 解码时 O(d²) per token
  • 16 层 GQA：每层 O(L²d)（全注意力），但由于 GQA-6 使 KV 头仅 4 个， 实际计算量远小于标准 MHA
图 5：KV 缓存与解码计算量对比。Hybrid 架构将 KV 缓存降至约 25%，解码计算量显著降低。

6.2 KV 缓存节省

在 262K 上下文下，纯 Transformer 需要 64 层 × L × KV 大小的缓存。 Qwen3.5-27B 的 DeltaNet 层仅维护固定大小的状态矩阵（16 头 × 128 × 128 = 256K 参数/层）， 与序列长度无关。只有 16 层全注意力需要传统 KV 缓存（4 个 KV 头 × 256 维）， 且使用 GQA-6 进一步压缩。这使得模型能够在有限显存下处理百万级上下文。

九、训练方法论

9.1 预训练

Qwen3.5-27B 采用了多阶段预训练策略，在海量多语言文本和多模态数据上进行训练。 关键训练特点包括：

  • 多模态联合预训练：从预训练早期即融合图文 token， 实现视觉与语言能力的同步发展，多模态训练效率接近纯文本训练的 100%
  • MTP 多步训练：使用额外 1 层预测头同时预测下一步 token， 提供更丰富的训练信号
  • 201 种语言覆盖：大幅扩展多语言数据，覆盖 201 种语言和方言

9.2 后训练与强化学习

Qwen3.5 系列在后训练阶段实现了大规模强化学习突破：

  • 百万级 Agent 环境：在百万级 Agent 环境中进行强化学习， 使用渐进复杂度的任务分布提升模型的实际适应能力
  • 异步 RL 框架：支持大规模 Agent scaffold 和环境编排的异步强化学习框架
  • 思维模式（Thinking Mode）：支持 <think>...</think> 格式的推理链输出，可通过 enable_thinking 参数控制开启/关闭
1

早期融合预训练

文本与视觉 token 混合训练，多模态效率 ≈ 纯文本 100%，视觉语言能力代际平齐。

2

MTP 多步预测

额外 1 层预测头在训练时提供前瞻梯度信号，推理时可用于投机解码加速。

3

大规模 Agent RL

百万级环境 + 渐进任务分布 + 异步 RL 框架，驱动 Agent 能力跃升。

4

超长上下文训练

原生 262K 训练，DeltaNet + GQA 混合架构天然支持高效百万级上下文扩展。

十、关键技术创新总结

1

Hybrid 3:1 架构

首次在大规模产品级模型中成功落地 DeltaNet + Attention 混合架构。 3:1 的层比例经过精心优化，在效率与精度之间取得最佳平衡。

2

Gated DeltaNet

在 Delta Rule 基础上增加遗忘门控 α、更新门控 β、短卷积和输出门控， 显著提升线性注意力的表达力和训练稳定性。

3

V/QK 头数不对称

V 头数是 QK 的 3 倍（48 vs 16），以更少的键索引驱动更大的值存储空间， 在固定参数预算下最大化信息容量。

4

Partial RoPE

仅在头维度的 25%（64/256）施加旋转位置编码， 降低位置编码对语义匹配的干扰，同时有利于超长序列外推。

5

M-RoPE 多分辨率位置

将 RoPE 维度拆分为 [11,11,10] 三段分别编码 H/W/T 视觉空间-时间位置， 实现视觉与语言 token 的统一位置编码。

6

统一多模态基座

图文视频共享同一模型，27 层 ViT 编码器通过线性投影对齐至语言模型， 早期融合训练消除了模态间的能力权衡。

十一、优劣势分析

优势

  • 27B Dense 模型达到旗舰级性能，部署门槛低
  • DeltaNet 层 O(1) 状态更新，解码延迟低
  • KV 缓存仅需 25% 层，支持超长上下文
  • IFEval 95.0、SWE-bench 72.4 超越 GPT-5-mini
  • 视觉语言统一架构，无需独立 VL 模型
  • 201 种语言覆盖，全球化部署友好
  • MTP 头支持投机解码，进一步加速推理
  • 思维模式可控，灵活适应不同场景

局限

  • DeltaNet 的递推状态容量有限（128×128），极端长序列的精确检索仍依赖全注意力层
  • CodeForces 1899，弱于 Qwen3-235B 的 2146，竞赛级编程仍需更大模型
  • 全注意力层的 KV 缓存仍随序列长度线性增长
  • 27B Dense 模型激活参数高于 MoE 的 Qwen3.5-35B-A3B（3B 激活）
  • DeltaNet 训练时分块并行效率低于标准注意力
  • Hybrid 架构的层间交互模式较复杂，调优难度较高

十二、总结与展望

Qwen3.5-27B 代表了混合线性-全注意力架构在大规模语言模型中的成功实践。 通过精心设计的 3:1 层布局（Gated DeltaNet + Gated Attention）， 模型在 27B 参数量下实现了与旗舰 MoE 模型（122B-A10B）相当甚至更优的性能， 同时大幅降低推理成本和显存需求。

其核心贡献可总结为三个层面：

  1. 架构层面：证明了 DeltaNet 线性注意力在大规模模型中的可行性和有效性， 3:1 的混合比例为后续研究提供了重要参考点。
  2. 效率层面：75% 的层无需 KV 缓存，使得百万级上下文在单机上成为可能， 解码阶段每 token 计算量显著降低。
  3. 能力层面：在多项基准上超越 GPT-5-mini 和 Qwen3-235B， 特别在指令遵循、数学推理、编程和 Agent 能力上表现突出。
展望： 混合线性注意力架构正成为下一代大语言模型的重要趋势。未来的演进方向可能包括： (1) 更激进的线性:全注意力比例（如 7:1 甚至更高）； (2) 将 DeltaNet 与 MoE 结合，进一步扩展模型容量； (3) 基于 DeltaNet 状态的硬件定制加速器设计； (4) 多模态 DeltaNet，直接在视觉 token 上使用线性注意力。
