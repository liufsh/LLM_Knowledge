大模型常用算子详解

构成 Transformer 的八大基础算子 —— 从数学定义到工程实现
Linear (MatMul) LayerNorm / RMSNorm Softmax Embedding Dropout Residual Add Activation (SiLU/GELU)

引言：Transformer 的"元件清单"

一个 Transformer 层看起来复杂，但拆解到最底层只有 7-8 种基础算子。 理解每种算子的数学定义、张量形状变化、计算量和在模型中的角色， 是理解 LLM 训练与推理性能的基础。

图 1：单个 Transformer 层中所有算子的位置。颜色标识：红色=线性层(MatMul)， 橙色=归一化(RMSNorm)，蓝色=注意力相关(Softmax+MatMul)，紫色=激活函数(SiLU)，蓝色=残差(Add)。
计算量分布：在典型的 LLM 中，Linear（矩阵乘法）占 ~99% 的 FLOPs， 其余所有算子（归一化、Softmax、激活、残差、Dropout）合计不到 1%。 但后者对训练稳定性、模型质量和数值精度的影响与 Linear 同等重要。

一、Linear（线性层 / 矩阵乘法）

1.1 定义

Y = X · W + b     X ∈ Rn×din, W ∈ Rdin×dout, Y ∈ Rn×dout

线性层是 Transformer 中最核心、最耗算力的算子。一个 Transformer 层包含 7 个线性层：Q/K/V 投影（3 个）、输出投影（1 个）、FFN 的 gate/up/down（3 个）。

图 2：线性层的矩阵乘法示意。输入 [6, 4096] 与权重 [4096, 11008] 相乘， 输出 [6, 11008]。FLOPs = 2 × 6 × 4096 × 11008 ≈ 541M。

GPU 上的实现：Linear 本质是 GEMM（通用矩阵乘法），GPU 通过 Tensor Core 高度并行执行。Prefill 阶段（n 大）是矩阵×矩阵（GEMM），GPU 利用率高； Decode 阶段（n=1）是矩阵×向量（GEMV），GPU 利用率极低——这就是 Decode 成为瓶颈的根因。

二、LayerNorm 与 RMSNorm

2.1 BatchNorm（批归一化）

BatchNorm(x) = γ · (x - μB) / √(σB2 + ε) + β

μB = mean(x, dim=batch),   σB2 = var(x, dim=batch),   沿 batch 维度计算

BatchNorm（Ioffe & Szegedy, 2015）是最早被广泛使用的归一化技术。 它沿batch 维度计算每个特征的均值和方差——即对一个 mini-batch 中所有样本的 同一个特征维度做统计，然后归一化。

BatchNorm 的计算步骤（以输入 X ∈ RB×D 为例）

  1. 计算每列（每个特征维度）的均值：μj = (1/B) ∑i X[i, j]，结果为 D 维向量
  2. 计算每列的方差：σj2 = (1/B) ∑i (X[i, j] - μj)2
  3. 归一化：X̂[i, j] = (X[i, j] - μj) / √(σj2 + ε)
  4. 仿射变换：Y[i, j] = γj · X̂[i, j] + βj（γ, β 可学习，各 D 个参数）
BatchNorm 在 LLM 中不可用的三大原因：
  • 依赖 batch 统计：推理时 batch=1（单条请求），无法计算有意义的 batch 均值/方差。 虽然可以用训练时的滑动平均，但在分布偏移时效果差。
  • 变长序列冲突：一个 batch 中不同序列长度不同，padding token 会污染统计量（见下图）。
  • 自回归不兼容：生成过程中序列逐 token 增长，每步的 "batch" 语义不断变化， batch 统计不稳定。

2.2 LayerNorm（层归一化）

LayerNorm(x) = γ · (x - μ) / √(σ2 + ε) + β

μ = mean(x, dim=feature),   σ2 = var(x, dim=feature),   沿 feature 维度计算

LayerNorm（Ba et al., 2016）彻底改变了归一化的维度——对每个样本（token）的特征向量 独立做归一化：减去该 token 自身特征的均值、除以标准差， 然后用可学习的缩放因子 γ 和偏移 β 进行仿射变换。

LayerNorm 的计算步骤（以单个 token 的特征向量 x ∈ RD 为例）

  1. 计算该 token 所有特征的均值：μ = (1/D) ∑j=0D-1 x[j]
    例：x = [1.0, 2.0, 3.0, 4.0]，μ = (1+2+3+4)/4 = 2.5
  2. 计算该 token 所有特征的方差：σ2 = (1/D) ∑j (x[j] - μ)2
    例：σ2 = ((1-2.5)2 + (2-2.5)2 + (3-2.5)2 + (4-2.5)2)/4 = 1.25
  3. 归一化：x̂[j] = (x[j] - μ) / √(σ2 + ε)
    例：x̂ = [-1.34, -0.45, 0.45, 1.34]（均值=0，标准差=1）
  4. 仿射变换：y[j] = γ[j] · x̂[j] + β[j]
    γ 和 β 是 D 维可学习参数，允许模型在需要时"撤销"归一化

2.5 RMSNorm（LLaMA 使用）

RMSNorm(x) = γ · x / RMS(x)   其中 RMS(x) = √(mean(x2) + ε)

RMSNorm 是 LayerNorm 的简化版本（Zhang & Sennrich, 2019）： 去掉了均值中心化（不减 μ）和偏移项 β，只做尺度归一化。

图 3c：BatchNorm、LayerNorm、RMSNorm 的归一化维度矩阵视图对比。 BatchNorm 沿 batch 维归一化（每列高亮）；LayerNorm 沿 feature 维归一化（每行高亮）； RMSNorm 与 LayerNorm 相同方向但不减均值。
图 4：归一化前后的数值分布。原始数据偏斜且方差大； LayerNorm 将其精确标准化为 mean=0, std=1；RMSNorm 将 RMS 归为 1 但保留均值偏移。

2.6 为什么 LLM 用 RMSNorm 而非 LayerNorm？

1

计算更快

省去均值计算（少一次 reduce）和偏移项。在大维度（d=4096+）下节省约 10-15% 的归一化耗时。

2

效果几乎无差

研究表明，均值中心化对 Transformer 的贡献极小——缩放（除以 RMS）才是关键。 去掉均值不影响模型质量。

3

参数更少

每层只有 γ（d 个参数），没有 β。对于 80 层的 LLaMA-65B， 共节省 80 × 2 × 8192 ≈ 1.3M 参数。

4

Pre-Norm 兼容性好

LLaMA 使用 Pre-Norm（归一化在子层之前），RMSNorm 在此场景下训练更稳定。

三、Softmax

3.1 定义

Softmax(xi) = exi / ∑j exj

Softmax 将任意实数向量转化为概率分布（所有元素 > 0，和为 1）。 在 Transformer 中有两个关键用途：

  • 注意力层：将注意力分数转化为注意力权重（每行和为 1）
  • 输出层：将 logits 转化为词表上的概率分布
图 5：Softmax 的效果。左：原始 logits；中：Softmax 后的概率分布（最大值被放大，小值被压缩）； 右：温度参数 T 对分布锐度的影响——T 越小越集中，T 越大越均匀。

3.2 数值稳定性

上溢问题：如果 xi 很大（如 1000），e1000 会溢出 float32。 解决方案：减去最大值 Softmax(x) = Softmax(x - max(x))，数学上等价但数值稳定。 这就是 FlashAttention 中 Online Softmax 需要维护局部最大值的原因。

3.3 计算量

Softmax 本身的 FLOPs 很少（每元素几个操作），但它包含一个 reduce 操作 （求 ∑exj），在 GPU 上需要跨线程同步，是一个潜在的延迟点。 对于注意力层的 [N×N] 矩阵，Softmax 沿每行 reduce，总量 = O(N2)。

四、Embedding（嵌入层）

4.1 定义

Embedding(token_id) = E[token_id]    E ∈ RV × d

Embedding 是一个查表操作（不是矩阵乘法）： 给定整数 token ID，直接取出嵌入表中对应行的 d 维向量。

图 6：Embedding 与位置编码的两种注入方式。 GPT-2 风格（Method A）：Token Embedding + Position Embedding 直接相加； LLaMA 风格（Method B）：只做 Token Embedding，位置信息由 RoPE 在 Attention 中注入。

4.2 Weight Tying

许多 LLM（包括 LLaMA）让 Embedding 表和输出层的 LM Head 共享同一个权重矩阵： 输入时用 E 做查表（token ID → 向量），输出时用 ET 做投影（向量 → logits）。 这节省了 V × d 个参数（LLaMA-7B: 32000 × 4096 = 1.31 亿参数）。

五、Dropout

5.1 定义

训练时：Dropout(x, p) = x · mask / (1 - p)    mask ~ Bernoulli(1 - p)

推理时：Dropout(x) = x   （不做任何操作）

Dropout 在训练时随机将一部分激活值置零（概率 p），并将存活的值 放大 1/(1-p) 倍（Inverted Dropout），使得训练和推理的期望值一致。

图 7：Dropout 过程可视化。左：原始激活值；中：30% 的元素被随机置零（红色 X）； 右：存活元素放大 1/0.7 倍，保持总期望不变。

5.2 在 LLM 中的使用现状

现代 LLM 趋势：不用 Dropout。LLaMA、Mistral、Qwen 等主流开源 LLM 在预训练中 完全去掉了 Dropout（p=0）。原因：
  • 大规模预训练数据本身就是最好的正则化（数据量 >> 参数量）
  • Dropout 引入随机噪声，不利于大 batch 训练的收敛稳定性
  • Dropout 的 mask 生成和存储有额外开销
  • 在超长序列训练中，激活值检查点（activation checkpointing）需要保存 Dropout 的 mask 才能精确重算，增加内存
不过在微调阶段（数据量小，易过拟合），Dropout 仍然常用（如 LoRA 中 p=0.05-0.1）。

六、残差连接（Residual Add）

6.1 定义

hl = hl-1 + fl-1(hl-1)

残差连接（He et al., 2016）是 Transformer 能够堆叠数十甚至上百层的关键保障。 它将子层的输出加回输入，而非替换输入。

图 8：残差连接对梯度传播的影响。没有残差时，梯度随层数指数衰减（每层乘以 <1 的系数）； 有残差时，梯度可以沿"高速公路"直接回传，保持 ~1.0 的幅度。

6.2 为什么残差有效？

  1. 梯度高速公路：反向传播时 ∂hl/∂hl-1 = I + ∂f/∂h， 恒等项 I 保证梯度至少以原幅度传播，不会消失。
  2. 渐进式精化：每层学习的是对输入的"增量修正"而非完整变换， 学习目标更简单，优化更容易。
  3. 隐式集成：展开后 hL = h1 + ∑fi(hi)， 相当于所有层输出的集成，类似 ensemble 效果。
计算开销：残差连接只是一个逐元素加法（element-wise add）， FLOPs = d（每个元素一次加法），对总计算量的贡献可忽略（<0.01%）。 但它是模型能训练成功的最关键操作之一。

七、激活函数（SiLU / GELU）

激活函数为网络引入非线性，使其能拟合复杂函数。在 Transformer 的 FFN 层中， 激活函数作用于中间的高维表示。

激活函数公式使用模型特点

八、其他重要算子

1

Masked Fill

将注意力矩阵的指定位置设为 -∞（因果掩码）。Softmax 后这些位置变为 0。 是实现自回归的关键——阻止 token "偷看"未来。

2

Concatenate / Split

多头注意力中，将 d 维向量拆分为 h 个 d/h 维的头（Split）， 注意力计算后再拼合（Concat）。纯内存操作，零 FLOPs。

3

Reshape / Transpose

调整张量形状和维度顺序。如 [B, T, h, d_k] ↔ [B, h, T, d_k]。 逻辑操作（改变 stride），不搬运数据。

4

Element-wise Multiply

SwiGLU 中 gate ⊗ up 的逐元素乘法，以及 RoPE 中的旋转操作。 FLOPs = 元素数，是"轻量级"操作。

5

Top-k / Argmax

输出层从 32000 个概率中选出最大值（greedy）或前 k 个候选（sampling）。 推理时每步只执行一次，开销可忽略。

6

Cross-Entropy Loss

训练时的损失函数：-log(P(正确 token))。包含 log-softmax + NLL loss。 只在训练时使用，推理时不需要。

十、总结

Transformer 的算子可以分为三类：

  1. 计算密集型（Linear）：占 99% 的 FLOPs，是训练和推理的主要计算负载。 所有性能优化的核心目标是让 GPU 的 Tensor Core 尽可能长时间地执行 GEMM。
  2. 数值稳定型（RMSNorm, Softmax）：FLOPs 很少但对训练至关重要。 没有 RMSNorm，深层网络无法训练；没有 Softmax，注意力权重无法归一化。
  3. 结构功能型（Embedding, Residual, Dropout, Activation, Mask）： 定义了模型的信息流结构——数据如何进入（Embedding）、如何跨层传递（Residual）、 如何引入非线性（Activation）、如何防止过拟合（Dropout）。
一句话理解：Linear 是 Transformer 的"肌肉"（提供计算力）， Normalization 是"免疫系统"（维持数值健康），Residual 是"骨架"（支撑深度）， Activation 是"关节"（提供灵活性），Softmax 是"大脑"（做出选择）， Embedding 是"感官"（接收输入）。缺一不可。
