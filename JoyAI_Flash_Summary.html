一、工作概述

JoyAI-LLM Flash 是 JD.com 发布的一个中等规模 MoE 大语言模型， 核心目标是重新定义 sub-50B 参数区间内"性能"与"token 效率"的权衡。 其独特之处在于不只追求 benchmark 分数高，而是追求 用更少的输出 token 达到相当或更高的准确率—— 这直接对应推理成本和用户等待时间。

二、模型架构

2.1 总体设计

JoyAI-LLM Flash 的架构灵感来自 DeepSeek-V3 和 Kimi-K2， 采用细粒度 MoE + MLA 的组合。这是当前 sub-50B 规模最高效的架构配置之一。

表 1：JoyAI-LLM Flash 48B-A3B 的详细架构配置。40 层 Transformer（1 层 Dense + 39 层 MoE）， MLA 注意力机制 (32 头，QK-RoPE=128, QK-NoPE=64, V=128)，256 个细粒度专家 + 1 共享专家，Top-8 路由，专家中间维度 768。

2.2 关键架构选择

1

Multi-head Latent Attention (MLA)

与 DeepSeek-V3 一致，使用低秩联合压缩 KV Cache，解耦 RoPE（NoPE 部分 + RoPE 部分）。 128K 长上下文下 KV Cache 显著小于标准 MHA。

2

细粒度 MoE (256 专家)

每层 256 个路由专家 + 1 个始终激活的共享专家，每 token 激活 Top-8 + 共享专家（共 9 个）。 门控分数用 sigmoid + FP32 计算保证稳定性，使用无辅助损失的负载均衡策略。

3

Muon 优化器

不用 Adam 而用 Muon——通过矩阵正交化执行 Newton 风格的谱范数更新。 实验显示 Adam 训练多次出现 loss spike 需要人工干预，而 Muon 全程稳定无异常。

4

Multi-Token Prediction (MTP)

附加单层 dense MTP 头，训练时丰富学习信号，推理时原生支持投机解码加速， 无需外部 draft 模型。

五、FiberPO：基于纤维化理论的 RL 算法（核心创新）

5.1 问题：PPO/GRPO/GSPO 的结构性缺陷

现代 LLM 是异构系统——agentic pipelines、MoE 条件路由、 分布式异步训练——在这种场景下 RLHF 的 PPO-style "proximal" 目标只提供粗粒度的局部控制 （主要是 per-token clipping），当问题来自全局结构（如轨迹漂移、专家分片）时无能为力。

具体失败模式：
  • Token-wise (PPO/GRPO)：对每个 token 的 ratio r_i 独立 clip。 一旦轨迹级漂移超过 clip bound，该轨迹中大部分 token 会同时饱和， 破坏 token-level 梯度区分，梯度坍缩到粗粒度的 trajectory-level 信号。
  • Sequence-wise (GSPO)：每个轨迹聚合为单一 ratio， 压制了轨迹内变化，优化器无法区分同一轨迹内 token 的质量差异， 导致概率质量分散到低效路径。

5.2 FiberPO 核心思想：纤维化解耦 (Fiber Bundle Gating)

FiberPO 建立在 Fibration Policy Optimization 的理论基础上—— 把采样的 RLHF 数据视作一个纤维丛（fiber bundle）结构： base space = 轨迹集合，fiber = 同一轨迹内的 token。 每个 token 的 log-ratio 被分解为两部分：

log ri = log r̄τ   +   (log ri − log r̄τ)
= 轨迹均值（base level）   +   token 偏差（fiber level）

FiberPO 的目标函数采用乘法因式分解：

G(r)i = wτbase  ·  r̃ifiber

base weight：wτbase = exp(gagg(log sτ+, C+, Tτ)) / exp(gagg(log sτ-, C-, Tτ))
gated residual：r̃ifiber = logclip((sτ(li))−li ri, ε) / logclip((sτ(−li))−li, ε)

关键设计：

  • Sign-channel 分解：根据 log ri 的符号，把轨迹分成"上漂"和"下漂"两个正负 channel， 分别追踪 sτ+ 和 sτ−，避免两者相互抵消
  • Piecewise-linear aggregate gate gagg：三段式线性门控—— pass-through（|x|≤C，原样通过） → rollback（C<|x|<(1+Tτ−1)C，反向斜率 −Tτ，产生回拉梯度） → zeroed（|x|≥阈值，完全冻结梯度）
  • fiber-level logclip on ui = li·log ri − log sτ(li)： clip 作用在 token 相对轨迹均值的偏差上，而非 log ri 本身
Token-Efficiency 优势（关键）： 因为 logclip 作用在 ui（token 相对轨迹均值的偏差），只有当 token 与轨迹均值方向相反偏离 > ε 时才会被 clip—— 与轨迹级漂移 log sτ(li) 本身的大小无关。 同方向漂移的 token 保留完整梯度信号，提供精细的 per-token 更新方向。 这是 PPO/GRPO 缺失的关键特性——它们直接对 log ri clip， 轨迹漂移一旦大于阈值，多数 token 同时饱和，token-level 区分能力崩溃。
图 4：FiberPO 门控行为可视化。
(a) 聚合门 gagg 的三段式：pass-through（|x|≤C）、rollback（C<|x|<C*，斜率 −Tτ）、zeroed（|x|≥C*）。
(b) 在 (log s+, log s−) 平面上的 base weight 热力图。 五个全局区域 (G-I 到 G-III) 对应不同 channel 的激活状态：双通道通透 → 单通道 rollback → 单通道全 gate → 双通道 rollback → 完全坍缩。 restorative rollback 是 PPO/GRPO/GSPO 中缺失的关键特性。

5.4 多域扩展

单域 RL 常导致 out-of-domain 能力退化（数学 RL 可能丢失指令跟随）。 FiberPO 通过 Gaussian curriculum 策略在多域上扩展：

μt = μ0 + (μT − μ0) · t/T    (μ0=0.8 easy, μT=0.2 hard)
wi(t) = exp(−½ · ((pi − μt)/σ)²),   σ=0.15

每个 prompt 预先用 K=10 次 rollout 估计通过率 pi，然后训练期间动态聚焦当前目标难度。 Domain balanced 权重 αg ∝ √Ng 保持多域平衡。 FiberPO 的 per-trajectory 信任域天然泛化到异质 reward 分布——无需任何多域特殊调整即可实现跨域稳定增益。

七、推理优化：QAT + MTP + PD 分离

7.1 Quantization-Aware Training (QAT)

JoyAI-LLM Flash 同时采用 QAT 和 PTQ。QAT 阶段在训练中插入 fake-quantization (Quantize → DeQuantize → Quantize) 模拟 INT4 量化，用 Straight-Through Estimator (STE) 处理不可微的 rounding/clamping。

意外发现：INT4 量化在 RL 阶段起到稳定器的作用—— 数值空间收窄使得模型 rollout 更鲁棒、减少噪声多样性。 JoyAI-LLM Flash 因此在低比特简单 RTN (Round-To-Nearest) 量化下仍保持高精度。
图 8：不同量化格式的准确率-吞吐量权衡。JoyAI-LLM Flash 的 FP8 版本提升 17% 吞吐，几乎无精度损失； W4AFP8 版本提升 28% 吞吐，仅下降 1.2% 精度。 Qwen3-30B-A3B FP8 吞吐只提升 10% 且有明显精度下降——JoyAI-LLM Flash 的量化鲁棒性显著更好， 尽管模型权重大 1.63×。

7.2 Multi-Token Prediction (MTP)

表 4：SpecBench MTP-3 投机解码性能对比。 JoyAI-LLM Flash 达到 1.87× 加速，超越 GLM-5 (1.82×)、DeepSeek-V3.2 (1.79×)、 Qwen3.5-35B-A3B (1.61×) 等，是对照表中最快的。
图 9：MTP 与量化的联合优化（ISL/OSL = 1K/2K, concurrency=64）。 BF16 和 FP8 最优 next-n=3，分别达到 1.57×、1.81× 加速； W4AFP8 在 next-n=2 达到最优 1.96× 加速。 next-n>3 因为额外预测开销产生收益递减。

7.3 推理服务调度

1

Short-context (Chat)

关心 TTFT + TPOT。建议 intra-node PD colocation 减少小模型的通信开销。AIConfigurator 动态调整 PD 实例比例匹配 SLA。

2

Long-context (RAG / Agent)

使用 PD disaggregation + Mooncake 集中 KV 缓存。 选择 P2P CPU 共享或 remote KV pooling 基于硬件；强烈不推荐 TCP 传输（延迟高）。

3

KV Cache 写策略

带宽充足时立即写到分布式 cache 层最大化命中； I/O 受限时减少写频率，使用 eviction policy 保留 hot data。

4

重计算 vs 传输

小模型对数据传输开销更敏感；即使 P2P RDMA 传输，延迟也可能超过重计算成本， 使集中 KV 管理成为负优化。需针对硬件做 crossover 分析。

八、核心创新点总结

1

Token Efficiency 作为第一目标

首个将"token 消耗"与"准确率"作为联合 Pareto 前沿优化的中等规模 LLM。 所有训练决策（thinking/non-thinking 混合、FiberPO、MTP）都服务于这个目标。

2

FiberPO RL 算法

基于 fibration 理论的新 RL 目标。把 token log-ratio 分解为 trajectory-level base weight 和 fiber-level gated residual，分别提供独立的 trust region。 严格解决 PPO/GRPO 在大漂移时的 token-level 区分崩溃问题。

3

Thinking / Non-thinking SFT 混合

故意在 SFT 中混合两种认知模式的数据。实验证明这种 hybrid 训练 显著增强了 non-thinking 模型的性能，而非期望的只对 thinking 模式有效。

4

MTP + QAT 联合优化

训练-推理协同设计：MTP 头在预训练丰富学习信号，推理时天然支持投机解码。 W4AFP8 + next-n=2 实现 1.96× 加速，达到同规模最优。

5

INT4 QAT 的意外 RL 稳定效果

发现 INT4 量化在 RL 阶段起到稳定器作用—— 收窄数值空间减少 rollout 噪声，提高鲁棒性。这是量化研究中少见的"量化反而有益"的发现。

6

细粒度 MoE + 强数学基座

256 细粒度专家 + Muon 优化器 + 20T tokens 四阶段课程， 在 MMLU-Pro / MATH / MATH-500 上超过 Qwen3.5-35B-A3B 等同规模模型。 基座 + 后训练共同驱动。

九、结论与意义

JoyAI-LLM Flash 在 sub-50B 参数区间重新定义了"性能"与"效率"的权衡： 不是更大的模型、不是更多的 token，而是更聪明的训练与推理协同。

三大核心突破：
  1. 训练方法论：FiberPO 是 RL for LLM 领域近年最具理论深度的进展之一， 首次把 token-level 和 trajectory-level 的 trust region 严格解耦，避免了 PPO/GRPO/GSPO 的结构性失败模式。
  2. 数据方法论：Thinking/Non-thinking 混合、Gaussian curriculum、 Agentic 可验证环境漏斗——这些系统化的数据工程是可复用的最佳实践。
  3. 工程方法论：QAT + MTP + PD 分离的训推一体设计， 为中等规模 MoE 模型在生产场景的部署提供了参考蓝图。

未来方向：团队计划引入 continual learning 和 persistent memory，使模型能够动态适应并持续累积知识。
