DeepSeek-R1：通过强化学习激励LLM的推理能力

DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning
DeepSeek-AI  |  research@deepseek.com

摘要

我们介绍第一代推理模型：DeepSeek-R1-Zero 和 DeepSeek-R1。DeepSeek-R1-Zero 通过大规模强化学习（RL）训练，无需监督微调（SFT）作为前置步骤，即展示出卓越的推理能力。通过 RL，DeepSeek-R1-Zero 自然涌现出许多强大且引人入胜的推理行为。然而，它遇到了可读性差和语言混杂等挑战。为解决这些问题并进一步提升推理性能，我们引入了 DeepSeek-R1，它在 RL 之前融入了多阶段训练和冷启动数据。DeepSeek-R1 在推理任务上达到了与 OpenAI-o1-1217 相当的性能。为支持研究社区，我们开源了 DeepSeek-R1-Zero、DeepSeek-R1，以及基于 Qwen 和 Llama 从 DeepSeek-R1 蒸馏而来的六个稠密模型（1.5B、7B、8B、14B、32B、70B）。

图 1 | DeepSeek-R1 的基准性能。在 AIME 2024（79.8%）、GPQA Diamond（71.5%）、MATH-500（97.3%）等推理任务上达到或超越 OpenAI-o1-1217；MMLU 90.8%；SWE-bench Verified 49.2%。

1. 引言

近年来，大语言模型（LLMs）经历了快速的迭代与演进（Anthropic, 2024; Google, 2024; OpenAI, 2024a），逐步缩小与通用人工智能（AGI）之间的差距。

最近，后训练已成为完整训练流程中的重要组成部分。它已被证明能够提高推理任务的准确性、与用户偏好对齐、适应社会价值观，同时相比预训练仅需相对较少的计算资源。在推理能力方面，OpenAI 的 o1 系列模型（OpenAI, 2024b）率先通过延长思维链长度引入了推理时间扩展。这种方法在数学、编程和科学推理等各种推理任务上取得了显著进步。然而，有效的测试时间扩展仍是研究社区的一个开放问题。此前的工作探索了多种方法，包括基于过程的奖励模型（Lightman et al., 2023; Uesato et al., 2022; Wang et al., 2023）、强化学习（Kumar et al., 2024），以及蒙特卡洛树搜索和束搜索等搜索算法（Feng et al., 2024; Trinh et al., 2024; Xin et al., 2024）。然而，这些方法都未能达到与 OpenAI o1 系列模型相当的通用推理性能。

在本文中，我们迈出了利用纯强化学习提升语言模型推理能力的第一步。我们的目标是探索 LLMs 在不依赖任何监督数据的情况下，通过纯 RL 过程专注于自我进化来发展推理能力的潜力。具体而言，我们使用 DeepSeek-V3-Base 作为基座模型，采用 GRPO（Shao et al., 2024）作为 RL 框架来提升推理性能。在训练过程中，DeepSeek-R1-Zero 自然涌现出许多强大且有趣的推理行为。经过数千步 RL 训练后，DeepSeek-R1-Zero 在推理基准上展现出超强性能。例如，AIME 2024 上的 pass@1 分数从 15.6% 提升至 71.0%，配合多数投票进一步提升至 86.7%，达到了 OpenAI-o1-0912 的水平。

然而，DeepSeek-R1-Zero 面临可读性差和语言混杂等挑战。为解决这些问题，我们引入了 DeepSeek-R1，它融入了少量冷启动数据和多阶段训练管线。具体而言，我们首先收集数千条冷启动数据来微调 DeepSeek-V3-Base。随后执行面向推理的 RL。在 RL 接近收敛时，通过拒绝采样从 RL 检查点生成新 SFT 数据，结合 DeepSeek-V3 在写作、事实问答、自我认知等领域的监督数据，重新训练 DeepSeek-V3-Base。微调后，该检查点经历额外的 RL 过程。经过这些步骤，我们获得了 DeepSeek-R1，其性能达到了与 OpenAI-o1-1217 不相上下的水平。

我们进一步探索了从 DeepSeek-R1 向更小稠密模型的蒸馏。使用 Qwen2.5-32B 作为基座模型，直接从 DeepSeek-R1 蒸馏并在其上应用 RL，效果优于单纯 RL。这表明大型基座模型发现的推理模式对于提升小模型推理能力至关重要。我们开源了蒸馏后的 Qwen 和 Llama 系列。蒸馏的 14B 模型大幅超越 QwQ-32B-Preview，蒸馏的 32B 和 70B 模型创下了稠密模型推理基准的新纪录。

1.1 贡献

后训练：在基座模型上进行大规模强化学习

  • 我们直接在基座模型上应用 RL，无需 SFT 作为前置步骤，让模型探索思维链以解决复杂问题，产生 DeepSeek-R1-Zero。它展示了自我验证、反思和生成长思维链等能力。这是首次公开验证 LLMs 的推理能力可以纯粹通过 RL 激励。
  • 我们介绍了开发 DeepSeek-R1 的管线：两个 RL 阶段（发现推理模式 + 人类偏好对齐）和两个 SFT 阶段（作为推理与非推理能力的种子）。

蒸馏：小模型也可以很强大

  • 大模型的推理模式可以蒸馏到小模型中，产生比直接在小模型上 RL 更好的性能。
  • DeepSeek-R1-Distill-Qwen-7B 在 AIME 2024 上达到 55.5%，超越 QwQ-32B-Preview。DeepSeek-R1-Distill-Qwen-32B 在 AIME 2024 上 72.6%，MATH-500 上 94.3%，LiveCodeBench 上 57.2%，可与 o1-mini 媲美。

1.2 评估结果总结

  • 推理任务：DeepSeek-R1 在 AIME 2024 上 79.8% Pass@1，略超 OpenAI-o1-1217。MATH-500 上 97.3%。Codeforces 上 2,029 Elo，超越 96.3% 人类参赛者。
  • 知识：MMLU 90.8%、MMLU-Pro 84.0%、GPQA Diamond 71.5%，显著超越 DeepSeek-V3。在 FRAMES 长上下文任务上表现出色。
  • 其他：AlpacaEval 2.0 胜率 87.6%，ArenaHard 胜率 92.3%，在长上下文基准上大幅超越 DeepSeek-V3。

2. 方法

2.1 概述

此前的工作大量依赖监督数据来提升性能。我们证明通过大规模 RL，即使不使用 SFT 冷启动，推理能力也能显著提升；加入少量冷启动数据后可进一步提高。我们将介绍：(1) DeepSeek-R1-Zero——直接在基座模型上应用 RL；(2) DeepSeek-R1——从微调后的检查点出发应用 RL；(3) 将推理能力蒸馏到小型稠密模型。

2.2 DeepSeek-R1-Zero：在基座模型上的强化学习

RL 在推理任务上已展示显著效果（Shao et al., 2024; Wang et al., 2023），但这些工作严重依赖监督数据。在本节中，我们探索 LLMs 在不依赖任何监督数据的情况下，通过纯 RL 实现自我进化来发展推理能力。

2.2.1 强化学习算法

Group Relative Policy Optimization（GRPO）  为降低 RL 训练成本，我们采用 GRPO（Shao et al., 2024），它放弃了与策略模型同等大小的 critic 模型，转而从组内分数估计基线。对于每个问题 q，GRPO 从旧策略中采样一组输出 {o1, o2, ⋯, oG}，然后通过最大化以下目标优化策略模型：

JGRPO(θ) = E[q ~ P(Q), {oi}Gi=1 ~ πθ_old(O|q)]
(1/G) ΣGi=1 [ min( (πθ(oi|q) / πθ_old(oi|q)) · Ai, clip(..., 1-ε, 1+ε) · Ai ) − β · DKL(πθ ∥ πref) ]   (1)
DKL(πθ ∥ πref) = πref(oi|q) / πθ(oi|q) − log(πref(oi|q) / πθ(oi|q)) − 1   (2)

其中 ε 和 β 为超参数，Ai 为优势值，使用组内奖励计算：

Ai = (ri − mean({r1, r2, ⋯, rG})) / std({r1, r2, ⋯, rG})   (3)

2.2.2 奖励建模

奖励是训练信号的来源，决定 RL 的优化方向。我们采用基于规则的奖励系统，包含两类：

  • 准确性奖励：评估回复是否正确。对于有确定性结果的数学问题，要求模型以指定格式给出最终答案，实现可靠的规则验证。对于 LeetCode 问题，使用编译器基于预定义测试用例生成反馈。
  • 格式奖励：强制模型将思考过程放在 <think> 和 </think> 标签之间。

我们没有使用神经奖励模型，因为在大规模 RL 中可能遭受奖励黑客问题，且重新训练奖励模型会增加复杂性。

自我进化过程  DeepSeek-R1-Zero 的思考时间在训练中持续增长，从生成数百到数千个推理 token。反思、重新评估、探索替代方法等复杂行为自发出现——这些并非显式编程，而是模型与 RL 环境交互的结果。

"顿悟时刻"（Aha Moment）

在训练的中间阶段，DeepSeek-R1-Zero 学会了通过重新评估初始方法来分配更多思考时间。在一个数学问题的求解中，模型突然输出："Wait, wait. Wait. That's an aha moment I can flag here."（等等，这是一个我可以标记的顿悟时刻。）然后重新开始推导。

这不仅是模型的"顿悟时刻"，也是研究人员的。它凸显了 RL 的力量：我们只需提供正确的激励，模型就能自主发展出高级问题解决策略。

缺陷  DeepSeek-R1-Zero 存在可读性差和语言混杂的问题。为此我们探索了配合人类友好冷启动数据的 DeepSeek-R1。

2.3 DeepSeek-R1：带冷启动的强化学习

受 R1-Zero 的启发，我们设计了四阶段管线：

2.3.1 冷启动

收集数千条长 CoT 数据微调 DeepSeek-V3-Base 作为 RL 的初始 actor。冷启动数据的优势：

  • 可读性：设计可读模式，在每个回复末尾包含总结，过滤不友好的回复。输出格式为 |special_token|<reasoning_process>|special_token|<summary>。
  • 潜力：带人类先验知识的冷启动数据比 R1-Zero 获得更好性能。

2.3.2 面向推理的强化学习

在冷启动数据上微调后，应用大规模 RL，聚焦编程、数学、科学和逻辑推理等任务。引入语言一致性奖励缓解语言混杂问题（计算为 CoT 中目标语言词的比例）。将准确性奖励与语言一致性奖励求和作为最终奖励。

2.3.3 拒绝采样与监督微调

RL 收敛后，通过拒绝采样收集约 60 万条推理数据和约 20 万条非推理数据（写作、事实问答等）。使用约 80 万样本对 DeepSeek-V3-Base 进行两个 epoch 微调。

2.3.4 面向所有场景的强化学习

第二阶段 RL 进一步对齐人类偏好，提升有用性和无害性。推理数据使用基于规则的奖励，通用数据使用奖励模型。对有用性仅评估最终总结，对无害性评估完整回复。

2.4 蒸馏：赋予小模型推理能力

使用 DeepSeek-R1 策划的 80 万样本直接微调 Qwen 和 Llama 开源模型。基座模型包括 Qwen2.5-Math-1.5B/7B、Qwen2.5-14B/32B、Llama-3.1-8B、Llama-3.3-70B-Instruct。蒸馏模型仅应用 SFT 不含 RL。

结论：(1) 蒸馏更强大的模型到小模型能产生优异结果；(2) 突破智能边界仍需要更强大的基座模型和更大规模的 RL。

4.2 不成功的尝试

过程奖励模型（PRM）

三个局限：(1) 难以在通用推理中定义细粒度步骤；(2) 判断中间步骤正确性困难；(3) 不可避免导致奖励黑客。在大规模 RL 中优势有限。

蒙特卡洛树搜索（MCTS）

挑战：(1) token 生成呈指数级搜索空间，设置最大扩展限制可能陷入局部最优；(2) 价值模型训练困难，难以迭代改进。通过自搜索迭代提升性能仍是重大挑战。

5. 结论、局限性与未来工作

DeepSeek-R1-Zero 代表纯 RL 方法，不依赖冷启动数据。DeepSeek-R1 更强大，利用冷启动数据配合迭代 RL 微调，达到与 OpenAI-o1-1217 相当的性能。蒸馏结果令人鼓舞：R1-Distill-Qwen-1.5B 在数学基准上超越 GPT-4o 和 Claude-3.5-Sonnet。

未来方向：

  • 通用能力：探索长 CoT 增强函数调用、多轮对话、角色扮演和 JSON 输出。
  • 语言混杂：解决非中英文查询时的语言混杂问题。
  • 提示工程：推荐 zero-shot 设置，避免 few-shot 降低性能。
  • 软件工程：通过拒绝采样和异步评估将大规模 RL 扩展到软件工程任务。
