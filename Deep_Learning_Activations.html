深度学习基础：激活函数详解

从 Sigmoid 到 SwiGLU —— 激活函数的演化之路
Sigmoid ReLU SiLU / Swish SwiGLU

引言：为什么需要激活函数？

在神经网络中，如果每一层都只做线性变换（矩阵乘法 + 偏置），那么无论堆叠多少层， 整个网络的表达能力等价于一个单层线性模型。激活函数为网络引入 非线性，使其能够拟合任意复杂的函数关系。

直觉理解：线性变换只能画直线（或超平面），而激活函数让网络能够 "弯曲"决策边界，从而区分非线性可分的数据。

一个好的激活函数需要平衡以下几点：计算效率、梯度传播能力、非线性表达力。 接下来我们将按时间线逐一介绍五种代表性的激活函数。

1943 / 经典

Sigmoid

最早的激活函数之一，将输出压缩到 (0, 1) 区间，模拟生物神经元的"激发"行为。

2010 / 突破

ReLU

极其简单的"取正值"操作，彻底改变了深度学习的训练方式，至今仍是最广泛使用的激活函数。

2015 / 改进

ELU

用指数曲线修复 ReLU 的负半轴，实现零均值输出和非零梯度，是 GELU 的思想前身。

2017 / 平滑

SiLU (Swish)

由 Google Brain 通过自动搜索发现，结合了 Sigmoid 的平滑性和 ReLU 的无上界特性。

2020 / 门控

SwiGLU

门控线性单元与 Swish 的结合，被 LLaMA、PaLM 等现代大语言模型采用。

一、Sigmoid 函数

1.1 数学定义

σ(x) = 1 / (1 + e-x)

Sigmoid 函数将任意实数映射到 (0, 1) 区间。当输入趋向正无穷时输出趋近 1， 趋向负无穷时输出趋近 0，x = 0 时输出恰好为 0.5。

1.2 直觉理解

可以把 Sigmoid 想象成一个"软开关"：

  • x 很大（正数）：开关几乎完全打开 → 输出接近 1
  • x 很小（负数）：开关几乎完全关闭 → 输出接近 0
  • x 在 0 附近：开关处于中间状态 → 输出在 0.5 左右

这种"S 形"曲线也常用于概率建模（如逻辑回归的输出层），将实数"挤压"为概率值。

图 1：Sigmoid 函数（左）及其梯度（右）。注意梯度最大值仅为 0.25，且在两端迅速趋近于 0。

1.3 梯度特性

σ'(x) = σ(x) · (1 - σ(x))

Sigmoid 的导数有一个优美的性质：它可以用自身来表示。但最大梯度值仅为 0.25 （在 x=0 处），且在输入绝对值较大时梯度迅速衰减至接近 0。

✓ 优点

  • 输出范围 (0,1)，可直接解释为概率
  • 处处可导，函数平滑
  • 导数可用自身表示，计算方便

✗ 缺点

  • 梯度消失：梯度最大仅 0.25，深层网络中梯度指数衰减
  • 输出非零中心：输出恒正，导致参数更新呈锯齿形
  • 计算代价：涉及指数运算
梯度消失问题：如果网络有 10 层，每层梯度最多乘以 0.25， 那么回传到第一层时梯度至多只剩 0.2510 ≈ 10-6， 几乎无法有效更新参数。这就是 Sigmoid 在深层网络中被淘汰的根本原因。

二、ReLU 函数

2.1 数学定义

ReLU(x) = max(0, x)

ReLU（Rectified Linear Unit，修正线性单元）的定义极其简洁： 负数输出为 0，正数原样输出。它于 2010 年左右被广泛应用于深度学习中， 是推动深度网络训练取得突破的关键因素之一。

2.2 直觉理解

ReLU 就像一个"硬开关"或者"单向阀门"：

  • 输入为正：信号完全通过，没有任何变形
  • 输入为负：信号被完全阻断，输出为 0

这种"要么全开、要么全关"的方式让网络产生稀疏激活—— 在任意时刻，只有部分神经元是"活跃"的，这类似于生物神经网络的工作方式。

图 2：ReLU 函数（左）及其梯度（右）。梯度只有两个值：0 或 1。负值区域的梯度恒为 0（"死亡区"）。

2.3 梯度特性

ReLU'(x) = { 0,   x < 0  ;  1,   x > 0 }

ReLU 的梯度非常"干净"：在正半轴恒为 1，完美避免了梯度消失。 这意味着在正值路径上，梯度可以无损地从输出层传回输入层。

✓ 优点

  • 无梯度消失：正区间梯度恒为 1
  • 计算极快：仅需一次比较操作
  • 稀疏激活：约 50% 的神经元输出为 0
  • 收敛速度快：比 Sigmoid 快约 6 倍

✗ 缺点

  • 神经元死亡：一旦输入始终为负，梯度永远为 0，该神经元永久失活
  • 输出非零中心：输出恒 ≥ 0
  • 不可导点：x=0 处不可导（实践中通常定义为 0 或 1）
"Dying ReLU" 问题：当学习率过大时，参数更新可能使某个神经元的输入 始终为负值。此后该神经元的梯度永远为 0，参数无法继续更新，相当于这个神经元"死了"。 实验中曾观察到多达 40% 的神经元出现这一问题。

三、ELU 函数

3.1 数学定义

ELU(x) = { x,   x > 0  ;  α(ex - 1),   x ≤ 0 }

ELU（Exponential Linear Unit，Clevert et al., 2015）是对 ReLU 的一种改进： 正半轴与 ReLU 完全相同，负半轴不再直接截断为 0，而是使用一条指数曲线 平滑地趋近于 -α。超参数 α（通常取 1.0）控制负饱和值。

3.2 直觉理解

ELU 可以看作 ReLU 的"升级版"——保留了 ReLU 正半轴的全部优点，同时修复了其两大缺陷：

  • 负值不再截断：当输入为负时，ELU 输出一个小的负值（而非硬性的 0）， 使得均值更接近零。这减少了前向传播中的偏移，加速收敛。
  • 梯度不再"死亡"：负半轴的梯度为 α·ex， 虽然很小但始终非零，避免了 ReLU 中神经元永久失活的问题。
  • 零点处平滑：ELU 在 x=0 处连续且可导（一阶导数连续）， 优化景观比 ReLU 更平滑。
图 3：ELU 函数（左）及其梯度（右）。不同 α 值控制负饱和程度。 与 ReLU 对比：负半轴梯度始终非零，零点处平滑过渡。

3.3 梯度特性

ELU'(x) = { 1,   x > 0  ;  α · ex = ELU(x) + α,   x ≤ 0 }

正半轴梯度恒为 1（与 ReLU 相同），负半轴梯度从 α（x=0 时）指数衰减至 0（x→-∞）。 注意：负半轴的梯度可以用 ELU 自身的输出值来表示（ELU(x) + α），这使得反向传播的计算更高效。

3.4 ELU 的变体

变体负半轴定义关键改进代表应用
SELU
(Scaled ELU)		 λ · α(ex - 1) 精心选择 λ=1.0507, α=1.6733，使网络自归一化（self-normalizing）—— 无需 BatchNorm 即可维持激活值的均值和方差稳定 全连接深层网络
CELU
(Continuously Differentiable ELU)		 α(ex/α - 1) 保证二阶导数也连续（ELU 仅一阶连续），优化更平滑 需要高阶优化的场景
GELU
(Gaussian Error LU)		 x · Φ(x) 用高斯 CDF 替代指数，输出更平滑。被 BERT、GPT-2 广泛采用， 可视为 ELU 到 SiLU 之间的过渡 BERT, GPT-2, ViT

✓ 优点

  • 无死亡神经元：负半轴梯度非零
  • 输出接近零均值：负值输出使均值偏移减小，加速收敛
  • 零点平滑：一阶导数连续（CELU 达到二阶连续）
  • 正半轴无梯度消失：梯度恒为 1

✗ 缺点

  • 计算代价：涉及指数运算 ex，比 ReLU 慢
  • 负饱和：x 很小时梯度趋近于 0，仍有轻微梯度消失
  • 非单调：与 ReLU 相同为单调函数（不如 SiLU 灵活）
  • 已被 SiLU/GELU 超越：在现代 LLM 中使用较少
ELU 的历史地位：ELU 是从 ReLU 到 SiLU/GELU 的重要"桥梁"。 它首次证明了负半轴的非零输出和梯度对训练的积极影响（零均值、无死亡神经元）， 这些思想被后续的 GELU（BERT）和 SiLU（LLaMA）继承并进一步发展。 在当前的 LLM 领域，ELU 本身已较少直接使用，但其变体 GELU 仍是 BERT 系模型的标准激活函数。

四、SiLU / Swish 函数

3.1 数学定义

SiLU(x) = x · σ(x) = x / (1 + e-x)

SiLU（Sigmoid Linear Unit）也被称为 Swish，由 Google Brain 团队 于 2017 年通过自动搜索（强化学习搜索激活函数空间）发现。 它是 Sigmoid 和恒等函数的乘积，看似简单，却在多项任务中持续优于 ReLU。

3.2 直觉理解

SiLU 可以看作一个"自门控"机制：

  • x 很大（正数）：σ(x) ≈ 1，SiLU(x) ≈ x，行为类似 ReLU
  • x 很小（负数）：σ(x) ≈ 0，SiLU(x) ≈ 0，信号被抑制
  • x 在 0 附近：输出 ≈ x/2，信号被"半开"通过

关键区别在于：SiLU 在负值区域并非完全为 0，而是有一个小的负值凹陷 （最低点约在 x ≈ -1.28 处，值约为 -0.28）。这种非单调性 是 SiLU 优于 ReLU 的重要原因——它允许少量负值信号通过， 类似于一种隐式的正则化效果。

图 4：SiLU (Swish) 函数（左）及其梯度（右）。注意函数在 x < 0 时不完全为零，梯度处处非零。虚线为 ReLU 参考。

3.3 梯度特性

SiLU'(x) = σ(x) + x · σ(x) · (1 - σ(x)) = σ(x) · (1 + x · (1 - σ(x)))

与 ReLU 不同，SiLU 的梯度处处非零——即使在负值区域， 梯度也不会完全消失。这意味着不存在"死亡神经元"的问题。同时， 梯度在正值区域可以超过 1（最大约 1.1），有利于梯度传播。

✓ 优点

  • 无死亡神经元：梯度处处非零
  • 平滑可导：处处连续可微，优化景观更平滑
  • 非单调：小的负值区域提供隐式正则化
  • 自门控：输入自身控制信息通过的比例

✗ 缺点

  • 计算代价：需要 Sigmoid 运算，比 ReLU 慢
  • 无稀疏性：输出不会精确为 0
  • 非零中心：仍然不完全以零为中心
为什么搜索发现了 Swish？Google Brain 使用强化学习在激活函数的组合空间中搜索， 评估标准是在 CIFAR-10 等任务上的验证准确率。最终搜索到的最优函数 f(x) = x · σ(βx) 在 β=1 时就是 SiLU，表明这种"自门控"模式确实是一种自然而优良的非线性选择。

五、SwiGLU 激活函数

4.1 前置知识：GLU（门控线性单元）

要理解 SwiGLU，需要先理解 GLU（Gated Linear Unit）的核心思想。 GLU 由 Dauphin 等人于 2017 年提出，核心理念是：让网络学习"该通过多少信息"。

GLU(x, W, V, b, c) = (xW + b) ⊗ σ(xV + c)

其中 ⊗ 表示逐元素乘法。输入 x 经过两组不同的线性变换：

  • 内容路径 (xW + b)：提取"信息内容"
  • 门控路径 σ(xV + c)：生成 0~1 之间的"门控信号"，决定每个维度上通过多少信息

两者逐元素相乘，就像为每个特征维度安装了一个独立的"音量旋钮"。

4.2 SwiGLU 定义

SwiGLU（Shazeer, 2020）将 GLU 中的 Sigmoid 门控替换为 SiLU (Swish)：

SwiGLU(x, W, V, b, c) = (SiLU(xW + b)) ⊗ (xV + c)

更直观的理解：

1

两条并行路径

输入 x 被送入两组独立的线性变换，各自提取不同的特征表示。

2

SiLU 激活

其中一条路径经过 SiLU 激活，引入非线性并产生门控信号。

3

逐元素相乘

两条路径的输出逐元素相乘，实现信息的选择性通过。

4

维度调整

LLaMA 中使用 2/3 × 4d 维度（而非 4d），抵消双路径带来的额外参数。

图 5：GLU 变体对比（左）——不同门控函数的输出形态；门控函数对比（右）——Sigmoid、ReLU、SiLU 作为门控的行为差异。

4.3 为什么 SwiGLU 更好？

Shazeer（2020）在论文中实验对比了多种 GLU 变体，发现 SwiGLU 在 Transformer 的 FFN 层中 持续优于其他变体。核心原因包括：

  1. 自适应特征选择：门控机制让模型学会对每个特征维度进行"软选择"， 而非像 ReLU 那样粗暴地截断负值。
  2. 平滑梯度景观：SiLU 的平滑性使得优化过程更稳定，减少训练中的震荡。
  3. 双路径增强表达力：两组独立参数让模型有更大的自由度来建模复杂映射。
  4. 非单调门控：SiLU 的非单调特性（小的负值区域）提供了额外的灵活性。
实际应用：SwiGLU 被 LLaMA、PaLM、Gemma、Mistral 等现代大语言模型广泛采用， 已成为 Transformer FFN 层的事实标准。在 LLaMA 中，使用 SwiGLU 替换传统的 ReLU FFN 后，模型在多个基准上获得了一致的性能提升。

七、演化脉络与总结

激活函数的演化反映了深度学习领域对梯度流和表达能力的持续追求：

  1. Sigmoid 开启了神经网络的非线性之旅，但梯度消失问题限制了网络深度。
  2. ReLU 以极简的设计解决了梯度消失，使训练数百层的深度网络成为可能， 但引入了"死亡神经元"的代价。
  3. ELU 用指数曲线修复了 ReLU 的负半轴，实现了零均值输出和非零梯度， 其思想被 GELU（BERT 的标准激活函数）继承发扬。
  4. SiLU (Swish) 通过"自门控"机制在 ReLU 的基础上实现了平滑性和非单调性， 消除了死亡神经元问题，在多项任务上取得了更好的效果。
  5. SwiGLU 将 SiLU 的优势与门控线性单元的双路径结构相结合， 为大语言模型的 FFN 层提供了更强的特征选择和表达能力，成为当前 LLM 的主流选择。
核心启示：没有"万能"的激活函数。选择取决于具体任务和架构—— CNN 中 ReLU 仍然高效可靠；大语言模型的 FFN 层首选 SwiGLU； 输出层的概率预测仍需 Sigmoid / Softmax。理解每种函数的优缺点， 才能在设计网络时做出最佳选择。
