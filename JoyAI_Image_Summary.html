一、工作概述

JoyAI-Image 是京东 Joy Future Academy 发布的一个统一多模态基础模型， 将图像理解、生成、编辑三个任务整合到一个框架中。与以往把这些任务拼接在一起的方案不同， JoyAI-Image 的核心主张是"唤醒空间智能"（awakening spatial intelligence）—— 把 3D/空间理解作为贯穿三个任务的第一类属性，而非事后补充的模块。

二、整体架构

图 2：JoyAI-Image 整体架构。三条路径共享同一组件： Understanding（MLLM 直接生成文本回答）； Generation（MLLM 解析 prompt → MMDiT 去噪 → VAE 解码）； Editing（MLLM 联合解析 instruction + source image → MMDiT 以 VAE-encoded 图像 + LLM prior + 噪声 token 为条件生成目标图像）。 右侧放大了 MMDiT block 的双流结构（文本流 + 视觉流），含 self-attention、QK-Norm、Scale&Shift modulation、gated residual 等组件。

2.1 三个核心模块

1

MLLM（认知大脑）

基于 Qwen3-VL-8B-Instruct，经过空间专门 SFT 强化。 双重角色：(1) 独立理解引擎处理纯 VQA/spatial reasoning； (2) 意图解析中介为 MMDiT 提供语义和空间先验。

2

VAE（潜空间桥梁）

采用 Wan-2.1-VAE，利用因果 3D 卷积实现优越的时空压缩。 保留高频细节（小文本、细纹理），这对 text-rendering 至关重要。

3

MMDiT（生成引擎）

16B 参数的双流 Multi-Modal Diffusion Transformer。40 层，32 attention heads， hidden dim 4096，使用 MRoPE 替代 Qwen-Image 的 MSRoPE， 更好地与空间条件对齐。

4

渐进训练

先 SFT MLLM 强化空间理解 → 从头训练 MMDiT（用 MLLM prior 作为条件）→ 最后微调整个框架支持 instruction-based editing。

三、空间理解：OpenSpatial-3M 数据引擎

3.1 核心挑战

现有 VLM 普遍缺乏 3D 空间智能——真实场景本质上由物体布局、相对几何、视角变化、跨视图一致性塑造， 而传统 2D 标注无法有效监督这些维度。 JoyAI-Image 的解法是构建一个以 3D box 为中心的数据引擎 OpenSpatial。

图 3：OpenSpatial 引擎流程。输入 3D 重建场景（ScanNet、Matterport3D、ARKitScenes、ScanNet++、Hypersim 等）， 通过人工标注 + 3D lifting得到 scene-level 3D oriented bounding box (OBB)， 然后通过严格的投影、可见性过滤、mask 细化管线，产生 object-frame 索引—— 包含 3D/2D box、instance mask、partial point cloud 和 metric 元数据。 下游分为 Single-view QA（从 per-frame scene graph 提取细粒度查询）和 Multi-view QA（跨重叠帧的视角不变推理）两个分支。

3.2 OpenSpatial-3M 的五大能力分类

图 4：OpenSpatial 数据集的五类任务样例： (1) Spatial Measurement (SM)：尺寸估计、距离、3D grounding； (2) Spatial Relationship (SR)：方位、前后、高低、多视角物体位置； (3) Camera Perception (CP)：相机运动、深度序、相机姿态； (4) Multi-view Consistency (MC)：跨视图对应、物体一致性； (5) Scene-Aware Reasoning (SAR)：场景描述、路径规划。 共 19 个子任务，300 万训练样本。

3.3 数据组成

图 5：JoyAI-Image 理解训练数据构成（总 11.3M 样本）。 左：总体分布——General Understanding 6.1M (54.25%)、Spatial Understanding 3.4M (29.65%)、 Prompt Enhancement 1.5M (13.2%)、Others 328K (2.9%)； 右：OpenSpatial 3.4M 的细分——Distance、Size、Position、Depth、Camera Pose Estimation 等。

3.4 训练目标：SFT + 在线知识蒸馏

L = LSFT + λ · LKL

λ = 10, LKL 使用冻结的 teacher 模型对中间隐藏状态做层平均的 KL 正则

关键设计：KL 正则只对 general-purpose 数据应用，对 spatial 数据关闭。 因为基座模型的空间能力本来就有限，KL 约束会阻碍新的空间知识获取； 而 general domain 的原始能力需要保护以防遗忘。

四、图像生成：JoyAI-Image T2I

4.1 五阶段数据流水线

T2I 训练数据管线是一个渐进式多阶段系统，共 5 个核心模块：

模块目的关键技术
1. Data Filtering从数十亿原始图像中筛选高质量样本In-house IQA（4 low-level + NIQE + CLIP-IQA + MUSIQ）；Caption-based 内容过滤
2. Captioning生成多层次、高保真的文本描述Short / Long / Extended Long / Structured JSON 四级 caption；OCR-aware 双语 captioning
3. Rebalancing矫正长尾分布偏差285K-tag 分类树 + embedding tagging + 逆对数下采样
4. Annotating人工标注高质量 SFT 数据三维评分：Aesthetics (50%) + Information Density (30%) + Style Purity (20%)
5. Multi-view Generation支持视角可控 T2IBlender 4.5 渲染 ~1M 多视图图像，dense + structured JSON 双提示

4.2 OCR-Aware Captioning：文本渲染的关键

图 6：OCR-conditioned captioning 管线。 对含文本的图像，先用 OCR-specialized 模型提取所有文字 token， 再让 caption model 基于视觉特征 + 识别的文字生成描述。 后过滤检查三个方面：(1) Text Coverage（所有 OCR 文字都被包含）、 (2) Language Integrity（原语言和措辞保留）、(3) Hallucination（文字准确）。 不满足的 caption 被丢弃。

4.3 Annotation 三维评分标准

表 1：人工标注的维度特定评分标准（0/3/4/5 四档）。 Aesthetics (50%) 关注视觉吸引力、构图、光照； Information Density (30%) 关注主体+对象+环境+交互的丰富度； Style Purity (20%) 关注风格一致性和是否有"AI 生成"痕迹。

4.4 训练：Pre-Training + Continue + SFT + RL

JoyAI-Image T2I 采用流匹配（flow matching）目标：

L = Et, z0, z1, y [ || fθ(zt, y, t) − (z1 − z0) ||² ]
其中 zt = t·z1 + (1−t)·z0，z1 是 VAE 潜变量，z0 是高斯噪声

训练过程分 4 个阶段：

  1. Pre-Training（三分辨率渐进）：208P → 512P → 1024P， 在 1024P 阶段加入多视图数据以培养 3D 意识
  2. Continue Training：用严格过滤的高质量子集"收窄分布"，稳定生成并抑制伪影
  3. SFT：task-oriented 数据，强化复杂文本渲染和多视图生成
  4. Reinforcement Learning (Flow-GRPO)： 基于 group-relative advantage，使用 aesthetic reward + text-image alignment reward 双重信号
JFlow-GRPO(θ) = E [ (1/G) Σ min(rt·Ât, clip(rt, 1−ε, 1+ε)·Ât) − β·DKL(πθ || πref) ]

Ât = (R(x0, c) − mean(R)) / std(R)

五、图像编辑：JoyAI-Image-Edit

5.1 编辑数据组成

图 8：JoyAI-Image-Edit 训练数据构成。 Open-domain Edit (46.72%)——来自视频帧的自然发生变化，覆盖人体动作、物体位移等； Spatial Edit (28.09%)——几何感知的编辑（Camera 12.72% + Rotation 7.98% + Moving 7.39%）； General Edit (25.20%)——含 IP Edit、Text Render 等 long-tail 任务。

5.2 Spatial Edit 数据引擎：Blender 合成管线

图 9：空间编辑数据生成管线，包含两个互补分支： Dynamic-Camera Viewpoint Transformation——固定 3D 场景，变化相机位置 （Yaw90、Pitch45、Pitch45+Zoom In 等），产生跨视图编辑对； Static-Camera Object Transformation——固定相机，对 3D 物体做旋转/平移/缩放， 使用 inpainting 保持背景一致性。两类数据共同提供了几何感知编辑的精确监督。

传统 2D 图像编辑数据很难提供几何上无歧义的监督——自然图像对中的视角变化、物体移动 大多是隐含的、不完全标注的。JoyAI-Image 通过 Blender 4.5 显式渲染 3D 场景， 把相机 6-DOF 运动和物体变换都作为可执行的指令模板，保证 source-target 对的几何一致性。

5.3 训练：Pre-Training → Continue → SFT → DiffusionNFT

编辑模型使用与 T2I 相同的 MMDiT 架构，但输入多了 source image 的 VAE 编码作为条件。 训练也分 4 个阶段：

  1. Pre-Training：从大规模生成先验初始化，引入粗粒度编辑监督（来自视频帧对）
  2. Continue Training：高质量编辑数据 + 专业分支（spatial、text、multi-image）
  3. SFT：针对指令遵循、文本准确性、空间精度、长尾 case 的精细调整
  4. RL (DiffusionNFT)：使用双奖励模型——
    • Gemini-3-Flash 作为 instruction-following + consistency 的 judge
    • HPSv3 作为 naturalness（感知质量）的 scorer
    • 采用 instruction-prioritized 线性混合，防止 reward hacking

DiffusionNFT 目标函数：

LNFT = E[ r · || vθ+(xr, xt, c, t) − v ||² + (1−r) · || vθ−(xr, xt, c, t) − v ||² ]

r ∈ [0,1] 是 sampled edit 的 optimality 概率

六、应用：Thinking with Novel Views（TwNV）

6.1 核心思想：把图像编辑当作推理工具

这是 JoyAI-Image 最有趣的创新之一——提出了一个生成式"视觉思维链"范式。 传统 VLM 回答空间问题时只能看一张固定的图，但有些空间关系从单视角本质上无法判断 （例如物体的背面、被遮挡的部分、视差下的高度关系）。

图 11：TwNV 三阶段管线。输入一张图 I0 和空间问题 Q， Stage 1: Planner（MLLM）输出 6-DOF 相机运动指令； Stage 2: Synthesizer（JoyAI-Image-Edit）渲染新视角 I1； Stage 3: Reasoner（MLLM）联合观察 {I0, I1} 回答问题。

图 12：TwNV 的两个代表性案例。 Case 1（高度比较）：查询"钟塔和房子哪个更高"， JoyAI-Image-Edit 生成的新视角（pitch 20°）清晰显示钟塔低于房屋（GT: House）， 而 Qwen-Image-Edit 和 Nano-Banana-Pro 的视角变化不忠实于指令。 Case 2（垂直关系消歧）：查询"交通灯是否直接在伞上方"， JoyAI-Image-Edit 通过 yaw -20° 的相机运动展示出"not directly above"的关系。 高保真的新视角生成让原本模棱两可的空间关系变得清晰可判。

6.3 3D 重建增强

TwNV 还被证明对下游 3D 重建有帮助。单张图输入 VGGT（feed-forward 3D reconstruction 模型） 得到稀疏、不完整的几何；用 JoyAI-Image-Edit 生成的多视图一起输入， 重建的点云明显更密集、更完整。

间接验证空间一致性：如果生成的视角只是"局部看起来对"但相机运动不一致， VGGT 会产生几何冲突并降低重建质量；但JoyAI-Image-Edit 的多视图一致提升了重建， 说明模型真的学到了跨视图几何一致性，而非仅仅的像素空间伪造。 这对 world model / embodied 应用意义重大。

八、核心贡献总结

1

统一的 MLLM+MMDiT 架构

不是模块拼接，而是紧耦合的双向协作范式——MLLM 既是独立理解引擎， 又是 MMDiT 的 intent 解析器；understanding 提升 generation/editing， 而 generation 产生的多视角反过来增强 spatial reasoning。

2

OpenSpatial-3M 数据引擎

以 3D box 为几何锚点，从 ScanNet/Matterport3D 等源头 lifting， 支持 single-view + multi-view 的 19 个子任务， 覆盖 Measurement/Relationship/Camera/Consistency/Reasoning 五大能力类别。

3

OCR-Aware 双语 Captioning

两阶段 OCR-conditioned 生成 + 三维后过滤（Text Coverage、Language Integrity、Hallucination）， 让 LongText-Bench EN/ZH 均达到 0.963 双 SOTA。 中英双语一致性远超 GPT Image 1（EN 0.956 / ZH 0.619）。

4

Blender Spatial Edit 引擎

3D 驱动的编辑数据合成：Static-Camera Object Transformation + Dynamic-Camera Viewpoint， 提供几何上无歧义的 source-target 对， 使 SpatialEdit-Bench 的 Moving Score 达到 0.652（次名的 1.75×）。

5

Thinking with Novel Views 范式

把图像编辑作为"视觉思维链"工具——Planner/Synthesizer/Reasoner 三阶段流水线 解决单视角空间推理的本质盲区。在参数受限的 reasoner 上获得 7.8% 相对提升（Small-Model Dividend）。

6

双重 RL + DiffusionNFT

T2I 用 Flow-GRPO（aesthetic + alignment 双奖励）； 编辑用 DiffusionNFT + Gemini-3-Flash + HPSv3 双 reward， instruction-prioritized 混合防止 reward hacking。

九、结论与意义

JoyAI-Image 代表了统一多模态模型的一个新方向：把空间智能作为第一类属性， 而不是事后增加的模块。三个任务（理解、生成、编辑）共享同一个空间底座， 使得它们可以互相强化——更强的理解驱动更精确的生成，而生成的多视角反过来 为 reasoning 提供新的视觉证据。

一句话总结： JoyAI-Image 不仅是一个性能更强的统一多模态模型，更是一个空间智能觉醒的实践蓝图—— 通过 3D box 为中心的数据引擎、几何感知的训练任务、和闭环的 understanding↔generation 耦合， 让 VLM 从"看图说话"走向"能够通过生成来推理几何"。 Thinking with Novel Views 的范式尤其有潜力—— 它预示着未来的 multimodal AI 可能不只是"理解现有图像"， 更能主动生成视觉证据来解决问题，这为 VLA（视觉-语言-动作）系统和世界模型 奠定了重要的基础。

未来方向

  • VLA 系统：将 spatial edit 能力嵌入机器人决策闭环，提供 "what-if" 视觉推理
  • World Models：更长 horizon 的多视图一致性，支持动态场景演化
  • Embodied Reasoning：主动探索策略，让 agent 根据不确定性主动生成"假设视角"
  • 更细粒度控制：从相机 6-DOF 到物体级关节运动、光照变换等
