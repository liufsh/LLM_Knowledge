Attention Residuals

Kimi Team (Moonshot AI)  |  arXiv:2603.15031  |  2026.03.16
用学习的深度注意力替代固定残差累加，突破 PreNorm 稀释瓶颈
论文总结报告

一、论文概述

标准残差连接（hl = hl-1 + fl-1(hl-1)）是现代 LLM 的基础构件， 但它以固定权重 1 累加所有层的输出，导致两大问题： (1) 隐藏状态幅度随深度 O(L) 增长（PreNorm 稀释）； (2) 早期层的信息被淹没，无法被后续层选择性检索。

核心提案：Attention Residuals (AttnRes) 用学习的 softmax 注意力 替代固定残差累加。每层通过一个伪查询向量 wl（d 维可学习参数） 对所有前驱层输出做 softmax 加权，实现内容依赖、选择性的深度聚合。

论文提出两个变体：Full AttnRes（全层注意力，O(Ld) 内存）和 Block AttnRes（分块注意力，O(Nd) 内存，N 为块数），并在 Kimi Linear 48B 模型上 验证了其有效性。

二、研究动机：标准残差的三大局限

2.1 PreNorm 稀释问题

展开标准残差递推 hl = h1 + ∑ fi(hi)， 可见第 l 层的隐藏状态是所有前驱层输出的等权求和。PreNorm 下 ||hl|| 随深度 O(L) 增长，每一层的相对贡献被逐步稀释——深层网络中，大量层可以被剪除而损失极小。

2.2 三大结构性局限

1

无选择性访问

每层只能访问压缩后的单一状态 hl-1，无法区分前驱各层的独立输出。 注意力层和 MLP 层接收相同的聚合状态，尽管它们可能需要不同的历史信息。

2

不可逆信息损失

一旦信息在累加过程中被淹没，后续层无法从聚合状态中选择性恢复。 早期层学到的精细特征可能被深层的大幅度输出覆盖。

3

输出幅度失控增长

深层需要学习越来越大的输出以对抗稀释效应，导致数值不稳定。 梯度分布也高度不均匀——早期层梯度远大于深层。

类比：标准残差对应序列维度的 RNN——将所有历史信息压缩为单一状态。 AttnRes 之于残差，正如 Attention 之于 RNN——用选择性注意力替代固定累加。

三、方法：Attention Residuals

3.1 Full AttnRes

AttnRes 将第 l 层的输入定义为对所有前驱层输出的 softmax 加权和：

hl = ∑i=0l-1 αi→l · vi     其中 αi→l = softmax( φ(ql, ki) )

关键设计：

  • 伪查询 ql = wl：每层一个可学习的 d 维向量（不依赖输入），训练时所有 wl 初始化为零（初始等权 → 等价于标准残差）
  • 键 ki = vi：v0 = h1（token embedding），vi = fi(hi)（第 i 层输出）
  • 核函数 φ：φ(q, k) = exp(qT RMSNorm(k))，RMSNorm 防止大幅度层主导注意力
图 1：三种残差结构对比。(a) 标准残差：固定等权累加；(b) Full AttnRes：每层通过学习的注意力权重选择性聚合所有前驱层输出；(c) Block AttnRes：层被分组为块，块内标准累加，块间注意力聚合。

3.2 Block AttnRes

Full AttnRes 的内存和通信开销为 O(Ld)，在流水线并行的大规模训练中不实际。 Block AttnRes 将 L 层分为 N 个块（每块 S = L/N 层）：

  • 块内：标准残差累加，形成块级表示 bn = ∑ fj(hj)
  • 块间：对 N 个块级表示做 softmax 注意力聚合
内存：O(Ld) → O(Nd)   |   实验中 N ≈ 8 即可恢复 Full AttnRes 的大部分收益
参数开销极小：每层仅新增 1 个 RMSNorm + 1 个 d 维伪查询向量 wl， 总新增参数量占模型总参数的可忽略比例。

四、工程实现：训练与推理优化

4.1 训练：跨阶段缓存（Cross-Stage Caching）

流水线并行中，标准残差只传递相邻阶段间的固定大小隐藏状态。Block AttnRes 需要传递 所有累积的块表示。朴素实现导致 O(C2) 的冗余通信。

解决方案：每个物理阶段缓存从前序阶段接收到的块表示， 后续虚拟阶段只传递增量块（新完成的块），避免重复传输。 这将峰值通信从 O(C) 降为 O(P)（P 为物理阶段数），实现与计算的完全重叠。

图 3：基于缓存的流水线通信示意（4 个物理 rank，2 个虚拟阶段）。 每个 rank 缓存已接收的块表示，阶段转换时只传递增量块（+[b1, b2]），而非完整历史。

4.2 推理：两阶段计算策略

推理时，Block AttnRes 采用两阶段计算以降低 I/O：

  1. Phase 1（并行）：块内所有 S 层的伪查询同时批量查询所有前序块表示， 只需读一次块表示 KV cache，摊销内存访问
  2. Phase 2（顺序）：块内逐层处理，使用 Online Softmax 将 Phase 1 的跨块结果 与当前块内的增量结果合并
推理延迟开销 < 2%：两阶段策略使得每层的 I/O 从 O(L) 降为 O(S+N)， 在典型推理负载下端到端延迟增加不到 2%。

五、缩放律实验

在 5 个模型规模（194M-528M 激活参数）上训练 Baseline、Full AttnRes 和 Block AttnRes， 验证改进在不同计算预算下的一致性。

表 2：缩放律实验配置和各变体的验证损失。Full AttnRes 在所有规模上取得最低损失，Block AttnRes 紧随其后。
图 4：缩放律曲线。拟合幂律后，在 5.6 PFLOP/s-days 时，Block AttnRes 达到与 Baseline 使用 1.25 倍计算量相同的损失（1.692 vs 1.714）——即 25% 的等效计算节省。

六、Kimi Linear 48B 大模型验证

八、理论洞察：序列-深度对偶性

8.1 结构化矩阵视角

论文提出了一个统一框架：所有残差变体都可以表示为深度混合矩阵 M 的不同形式， 其中 Mi→l 是第 l 层赋予第 i 层输出的权重。

图 9：四种残差变体的深度混合矩阵 M（L=4）。标准残差：全 1 下三角矩阵（等权累加）； Highway：通过门控因子分解的软 softmax-free 变体；Full AttnRes：基于 φ 核的全密集矩阵； Block AttnRes：块内共享权重，块间独立注意力。

8.2 从线性注意力到 softmax 注意力

关键洞察： 标准残差 = 深度维度的线性注意力（固定权重，无归一化）。 Highway / mHC = 深度维度的门控线性注意力（可学习权重，但无竞争性归一化）。 AttnRes = 深度维度的softmax 注意力（内容依赖，竞争性归一化）。

这完成了深度维度上"从线性到 softmax"的同一过渡，正如 Transformer 在序列维度上所做的那样。

九、核心创新点总结

1

深度维度的 softmax 注意力

首次将标准残差连接重新定义为深度维度的线性注意力，并用 softmax 注意力替代， 实现内容依赖、选择性的跨层信息聚合。

2

Block AttnRes 的可扩展设计

将 O(Ld) 内存降为 O(Nd)（N≈8），通过块内标准累加 + 块间注意力， 在保持大部分收益的同时实现工程可行性。

3

缓解 PreNorm 稀释

选择性聚合将输出幅度限制在有界周期性模式中，梯度分布更均匀， 从根本上解决了深层网络中层贡献被稀释的问题。

4

近零开销的工程实现

跨阶段缓存消除冗余通信，两阶段推理策略使延迟增加 <2%， 训练开销 <4%。作为标准残差的即插即用替代方案。

5

序列-深度对偶性理论

建立了残差连接与序列注意力的形式化对偶关系， 统一了 Residual/Highway/mHC/AttnRes 等变体在结构化矩阵框架下的分析。

6

48B 规模验证

在 Kimi Linear 48B (MoE) 架构上 1.4T token 预训练验证， 15 个下游基准全面提升，缩放律显示等效 25% 计算节省。

十、结论

Attention Residuals 揭示了残差连接中长期被忽视的信息聚合局限， 并通过一个优雅的解决方案——深度维度的 softmax 注意力——实现了选择性的跨层信息路由。

一句话总结： 正如 Transformer 用注意力替代 RNN 解决了序列维度的信息压缩瓶颈， AttnRes 用注意力替代固定残差累加，解决了深度维度的同一瓶颈。 Block AttnRes 以 N≈8 个块表示、不到 2% 的推理开销， 实现了 25% 等效计算节省和全面的下游性能提升， 是标准残差连接的实用升级方案。
